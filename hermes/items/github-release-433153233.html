Hermes Agent v0.22.7 공식 패치 릴리스: CLI·Docker·Cloud 안정판 통합

Hermes Agent v0.22.7

지정 후보의 ID·content_hash를 확인했고, 후보의 원문 제목·태그·본문을 공식 GitHub Releases 페이지와 대조했다. 최종 URL은 동일한 공식 v0.22.7 릴리스 페이지이며 HTTP 200을 확인했다. 정식 안정 태그와 배포 경로별 업데이트 안내가 새로 제공된 의미 있는 공식 릴리스이므로 게시 및 대표 후보에 적합하다. 설치나 자동 업데이트는 수행하지 않는다.

핵심 요약

NousResearch가 v0.22.6 이후 병합된 174개 PR을 통합한 Hermes Agent v0.22.7 안정 패치 릴리스를 공개했다. 원문은 Desktop Group Chats의 선택형 리드 라우팅과 그룹 채팅으로 게시하는 cron 작업, Slack의 선택형 thread_followup_silence 등 운영 관련 변경을 언급한다. 전체 상세 릴리스 노트는 v0.23.0에서 제공할 예정이다.

왜 중요

새 공식 안정 태그가 CLI·Microsoft Store·Docker·Hermes Cloud 배포에 적용되므로, 운영자가 업데이트 검토 기준을 새로 잡을 수 있다. 설치형 Desktop 앱은 이번 릴리스에서 변경되지 않는다고 명시되어 있어 배포 경로별 적용 범위를 구분해야 한다.

우리 영향

CLI는 hermes update 또는 설치 스크립트 재실행, Microsoft Store 앱은 Store를 통한 업데이트가 안내되어 있다. Docker·Hermes Cloud는 nousresearch/hermes-agent:stable 또는 :latest를 안내한다. .exe·.dmg 설치형 Desktop 앱은 다음 번들 릴리스에서 업데이트된다. 이 공지는 현재 운영 환경의 설치 버전이나 업데이트 완료를 의미하지 않는다.

지금 할 일

공식 릴리스 공지로 게시하고 설치 방식별 업데이트 검토 대상으로 관리한다. 실제 업데이트는 자동 수행하지 않으며, 적용 전 사용 중인 태그·설정·플러그인 호환성과 백업·복구 절차를 확인한 뒤 별도 승인으로 진행한다. 원문에 없는 보안 취약점이나 breaking change를 확정하지 않고, 관련 징후가 생기면 escalation 후보로만 표시한다.
