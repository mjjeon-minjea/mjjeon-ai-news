Hermes Agent v0.23.5 공개: 게이트웨이·도구·프로필 운영 변경 통합

Hermes Agent v0.23.5

게시 적합. 제공된 후보 snapshot의 제목·태그·변경 내용이 공식 릴리스 원문과 일치하며, 릴리스·저장소·공식 문서 URL의 최종 HTTP 200을 확인했다. 신규 안정 릴리스와 운영 변경이 있어 meaningful change 및 공식 대표 항목 자격을 인정한다. 원문에 보안 취약점이나 breaking 변경이 명시되지는 않았으며, 이후 보안·breaking·교차신호 조건이 확인되면 escalation 후보로만 표시한다. 원문 Release Date는 2026-11-27이고 게시시각은 후보의 2026-11-28T03:20:13Z를 보존한다.

핵심 요약

Nous Research가 v0.23.4 이후 병합된 338개 PR을 통합한 안정 패치 릴리스 v0.23.5를 공개했다. 공식 노트는 CLI·TUI의 OSC 7577 세션 재개, 유휴 게이트웨이 대화의 백그라운드 압축, read_file·search_files 개선, 게이트웨이 시작 전 기본 플러그인 사전 점검, 프로필 이름 변경·이동·삭제 시 플러그인 작업 범위 수정 등을 언급한다. 해당 기간의 전체 정리 노트는 v0.24.0에서 제공할 예정이다.

왜 중요

단순 버전 표기 변경이 아니라 대화 압축·도구 사용·플러그인 시작과 프로필 격리에 영향을 주는 변경을 안정 배포에 묶었다. 공식 릴리스 원문과 저장소의 최신 릴리스 링크를 대조했고 공식 문서 연결도 확인해, 운영자가 검토할 의미 있는 공식 업데이트로 판단했다.

우리 영향

공식 안내의 적용 경로는 CLI·설치 스크립트, Microsoft Store, Docker·Hermes Cloud다. Store 앱은 Store를 통해 갱신되지만 .exe·.dmg 설치형 Desktop 앱은 이번 릴리스에서 변경되지 않고 다음 번들 릴리스에서 갱신된다. Solstice의 stateless Interactions API 전환과 플러그인 OAuth 리디렉션 URI 고정 지원도 언급되어 해당 기능 사용자는 호환성 확인이 필요하다. 이 게시물은 실제 설치 버전이나 이미지 태그가 가리키는 빌드를 확인한 결과가 아니다.

지금 할 일

설치 방식과 현재 버전을 확인하고, 게이트웨이 유휴 압축·세션 재개·플러그인 시작·프로필 격리 동작을 점검한 뒤 업데이트를 검토한다. CLI는 공식 hermes update 경로, Store는 Store 갱신, Docker·Cloud는 공식 이미지 경로를 따른다. 이 뉴스 게시 작업에서는 설치 업데이트나 컨테이너 재시작을 실행하지 않는다. 전체 변경 설명은 v0.24.0 정리 노트에서 후속 확인한다.
