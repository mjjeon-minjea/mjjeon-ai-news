Hermes Agent v0.23.4

게시 승인. 제공된 후보의 ID·해시를 유지하고 공식 GitHub 릴리스 원문에서 제목·태그·주요 내용의 일치를 직접 확인했으며, 리디렉션 확인 후 최종 공식 URL의 HTTP 200도 확인했다. 기존 게시 항목은 제공된 비교 입력상 없고, 신규 안정판 배포는 의미 있는 운영 변경이므로 공식 대표 항목 자격을 부여한다. 본문 Release Date는 2026-11-23이지만 published_at은 후보의 GitHub 공개 시각 2026-11-24T08:17:06Z를 보존한다. 보안 취약점 수정이나 breaking change를 확정하지 않으며, 보안·breaking·추가 교차신호 조건은 확인될 경우에만 escalation 후보로 다룬다.

핵심 요약

NousResearch가 Hermes Agent v0.23.4 패치 릴리스를 공개했다. 공식 설명에 따르면 v0.23.3 이후 병합된 229개 PR을 GitHub 배포, Microsoft Store, Docker 및 Hermes Cloud용 안정판에 통합했다. 이 변경 구간에는 기존 serve/dashboard 백엔드를 gateway로 옮기는 명령, 터미널 플러그인 설정 편집, Desktop 승인 카드와 스트리밍·대화 기록 성능 개선 등이 포함된다. 전체 정리 릴리스 노트는 v0.24.0에서 제공할 예정이다.

왜 중요

단순 문구 수정이 아니라 안정판 배포와 운영 기능 변경을 알리는 공식 릴리스다. 특히 gateway 백엔드 이전과 플러그인 설정 관리가 운영에 영향을 줄 수 있고, 배포 형태별 업데이트 적용 시점이 달라 동일 버전 공지만으로 모든 앱이 갱신됐다고 판단하면 안 된다.

우리 영향

Microsoft Store 앱은 Store를 통해 갱신된다. 설치 프로그램으로 설치한 Desktop 앱(.exe/.dmg)은 이번 릴리스에서 변경되지 않으며 다음 번들 릴리스에서 업데이트된다. CLI에는 hermes update 또는 설치 프로그램 재실행이 안내됐고, Docker·Hermes Cloud에는 nousresearch/hermes-agent:stable 또는 :latest 이미지가 안내됐다. 이 공지만으로 현재 운영 환경의 설치 버전이나 업데이트 완료 여부를 확정하지 않는다.

지금 할 일

공식 릴리스 원문과 자신의 설치 형태를 대조해 업데이트 경로를 선택하고, gateway 이전이나 운영 환경 업데이트는 영향 검토와 별도 승인 후 수행한다. 이번 작업은 뉴스 게시만 진행하며 설치·Docker·Gateway를 자동 변경하지 않는다. 상세 변경 내역은 공식 비교 링크와 추후 v0.24.0 정리 노트에서 확인한다.
