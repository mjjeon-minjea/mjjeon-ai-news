SUPPORTING · REVISION 1

NousResearch, Grok Bot의 Hermes 이전 명령 안내 — 공식 문서·병합 PR로 확인

> hermes migrate grok-bot

게시 승인: Hermes 운영 변경을 공식 Docs, 병합 PR https://github.com/NousResearch/hermes-agent/pull/147724 및 공식 릴리스 노트 https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.6 로 교차검증했다. 공식 문서 색인과 저장소의 최종 URL은 각각 HTTP 200으로 확인했다. X 원글은 supporting/social로 유지하고 대표 기사에서는 제외한다. 보안·breaking 변경은 이 원글만으로 확정하지 않으며, 공식 출처와의 교차신호는 escalation 후보로만 표시한다. 릴리스 노트의 버전은 출처의 표기이며 현 환경의 설치 버전을 의미하지 않는다.

핵심 요약

NousResearch가 원글에서 ‘hermes migrate grok-bot’을 안내하고 같은 스레드의 후속 답글로 공식 PR #147724를 연결했다. 해당 PR은 main에 병합됐으며, 공식 가져오기 문서와 v0.22.6 릴리스 노트에서도 Grok Bot·OpenBot의 설정 및 migrate 경유 이전 지원을 확인했다. 원글 자체는 답글이나 리트윗이 아닌 스레드 시작 글로 확인되며, X 게시물은 공식 문서를 보완하는 보조 신호로만 취급한다.

왜 중요

단순 홍보가 아니라 다른 에이전트의 작업을 Hermes로 이전하는 운영 절차 변경이다. 공식 문서에 따르면 Grok Bot의 예약 루틴은 기본적으로 일시정지된 cron 작업으로 이전되므로 중복 실행 방지와 출력 전달 대상 확인이 중요하다.

우리 영향

Grok Bot·OpenBot에서 이전하는 운영자에게 해당하며 기존 Hermes 환경에 즉시 변경을 강제하지 않는다. 가져오기 플러그인 지원 여부, 봇별 대상 프로필, 예약 작업의 활성화 상태와 전달 대상을 확인해야 한다. 이 X 글로 현재 설치 버전이나 업데이트 필요성을 확정하지 않는다.

지금 할 일

이전이 필요한 경우에만 공식 문서의 미리보기·확인 절차에 따라 검토한다. 기존 봇의 예약 실행을 중지하고 가져온 작업의 전달 대상을 확인한 뒤 명시적으로 활성화한다. 이번 검토로 설치·업데이트·이전 명령을 실행하지 않는다. 공식 문서: https://hermes-agent.nousresearch.com/docs/user-guide/import-from-other-agents
