핵심 요약

v0.20.2 이후 약 125개 PR을 묶은 공식 패치 릴리스입니다. MCP 2.x SDK와 무상태 프로토콜 지원, Bot Mode 및 CommandCode 플러그인, Python 하위 프로세스 격리 강화, cron 자동 복구와 세션 인계 데이터 손실 수정 등이 포함됐습니다.

MCP 2.x 전환과 Cua Driver 0.20 계약, 플러그인 설치 보안 검사 및 런타임 격리 변경은 기존 연동·플러그인·자동화 작업의 호환성에 영향을 줄 수 있습니다.

지금 할 일

자동 업데이트하지 말고 현재 구성의 MCP 서버, 플러그인, cron, 세션 인계 및 Desktop 원격 연결을 스테이징에서 회귀검증한 뒤 적용 여부를 결정합니다.
