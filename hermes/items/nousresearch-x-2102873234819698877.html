Hermes Desktop, Bot Screen 실시간 화면 스트리밍과 사용자 개입 지원

You can now watch your agents work live as Hermes Desktop streams the screen of any bot's screen or session in real time.

보조 신호 · 독립 원글 확인 · 답글·리트윗 아님 · 공식 Releases·Docs·repository 교차확인 · Bot Screen 운영 변경 유의미 · 자동 업데이트 금지 · 보안·교차신호 에스컬레이션 후보 · 명시적 breaking 근거 없음

핵심 요약

NousResearch는 공식 X 독립 원글에서 Hermes Desktop이 봇의 화면이나 세션을 실시간 스트리밍해 브라우저·터미널·창 작업을 지켜보고, 사용자가 언제든 제어권을 넘겨받아 상호작용하거나 자격 증명을 입력한 뒤 다시 봇에 넘길 수 있다고 발표했습니다. 원글은 답글이나 리트윗이 아니며, 공식 Docs의 Bot Screen 문서 색인과 v0.21.5 릴리스, 공식 저장소의 hosted Bot Screen 구현 기록으로 운영 변경을 교차확인했습니다.

왜 중요

에이전트의 컴퓨터 사용을 결과만 확인하는 대신 진행 중인 화면을 관찰하고 필요한 순간 사람이 직접 개입할 수 있어 원격 자동화의 감독·복구 흐름이 달라집니다. 다만 X 글은 설치 버전이나 배포 완료 범위를 확정하는 대표 출처가 아닙니다.

우리 영향

지원되는 Hermes Desktop과 Bot Screen 환경에서는 봇의 브라우저·터미널·창 작업을 실시간으로 보고 제어권을 주고받을 수 있습니다. 공식 v0.21.5 릴리스는 hosted `-desktop` 이미지의 Bot Screen 제공을 확인하지만, 기존 설치가 자동으로 지원되거나 갱신되는 것은 아닙니다. 화면 스트림과 자격 증명 입력은 민감정보 노출·세션 권한·접근 통제에 영향을 줄 수 있어 보안 에스컬레이션 후보입니다.

지금 할 일

X 글만으로 설치·릴리스 버전을 확정하거나 자동 업데이트하지 않습니다. 공식 Releases·Docs·repository에서 현재 배포 범위와 요구사항을 확인한 뒤 별도 시험 환경에서 Desktop 연결, 화면 스트림 접근 권한, 사용자 제어권 인계, 자격 증명 입력 시 비밀정보 노출, 세션 격리와 hosted `-desktop` 이미지 호환성을 검증하고 단계적으로 적용합니다.
