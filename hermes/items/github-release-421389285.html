Hermes Agent v0.22.5 공식 패치 릴리스: 로그인·업데이트 복구 개선과 플러그인 분리

Hermes Agent v0.22.5

지정 ID와 hash가 일치하는 공식 GitHub Releases 후보를 직접 검토했다. 원문 릴리스 조회와 리다이렉트 추적 GET에서 최종 공식 URL 및 HTTP 200을 확인했으며 draft·prerelease가 아닌 정식 패치 공개와 구체적 운영 변경을 근거로 meaningful change 및 대표 기사 적격으로 판단한다. published_at은 후보의 GitHub 공개 시각을 보존했으며 본문 표기 릴리스 날짜는 2026-10-22다. 보안·breaking 검토는 escalation 후보이며 실제 설치 변경은 수행하지 않는다.

핵심 요약

NousResearch가 Hermes Agent v0.22.5를 정식 패치 릴리스로 공개했다. 공식 설명에 따르면 v0.22.4 이후 약 81개 병합 PR을 묶었으며, Nous 기기 로그인 흐름 개편, Windows 업데이트 런처 문제 수정, 손상된 Git 상태 이후 일시 중지된 게이트웨이 복구, 사용량 윈도 기반 요금제 표시·모델 전환 복구 등을 포함한다. 위임 백엔드 선택 기능이 추가되고 hermes import-agent, OpenClaw 마이그레이션, hermes mcp serve, Singularity 백엔드는 코어에서 플러그인으로 이동한다. 의존성 보안 업데이트도 언급됐으며, 전체 정리 릴리스 노트는 v0.23.0에서 제공될 예정이다.

왜 중요

로그인·업데이트·게이트웨이 복구는 상시 운영 안정성에 직접 영향을 준다. 일부 기능의 플러그인 분리는 기존 가져오기·MCP·백엔드 사용 환경의 호환성 확인이 필요한 실질적 운영 변경이다.

우리 영향

공식 안내상 CLI는 hermes update 또는 설치 스크립트 재실행, Microsoft Store 앱은 Store를 통해 업데이트한다. Docker·Hermes Cloud에는 stable 또는 latest 이미지가 안내됐다. 설치형 데스크톱 앱의 .exe·.dmg 배포본은 이번 릴리스에서 변경되지 않으며 다음 번들 릴리스에 반영된다. 릴리스 공개 사실은 운영 환경의 설치·업데이트 완료를 뜻하지 않는다.

지금 할 일

자동 업데이트하지 않는다. 운영 반영 전 별도 검증 환경에서 로그인·게이트웨이 재개·Windows 업데이트 경로를 확인하고, 해당 기능을 사용하는 경우 가져오기·MCP serve·Singularity 플러그인의 설치 및 기존 설정 호환성을 점검한다. 의존성 보안 변경과 플러그인 분리에 따른 breaking 가능성은 escalation 후보로만 표시하며, 취약점 심각도나 호환성 단절을 확정하지 않는다.
