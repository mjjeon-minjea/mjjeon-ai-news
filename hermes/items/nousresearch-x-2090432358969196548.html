Hermes Cloud 프리뷰: 호스팅 원격 Hermes Agent 운영 신호

Hermes Agent has its own remote computer too, you just aren’t locked in to using it and it costs a few dollars per month instead of $200.

핵심 요약

NousResearch의 원글은 Hermes Agent를 원격 컴퓨터에서 운영하는 자체 선택지로 Hermes Cloud를 소개합니다. 연결된 공식 Cloud 페이지는 현재 프리뷰이며, 원클릭 배포·상시 실행·예약 작업·메시징 채널 연결·지속 메모리·격리 컨테이너를 제공한다고 설명합니다. 다만 X 글의 ‘월 수 달러’와 200달러 비교는 공개 공식 가격표에서 독립 확인되지 않아 확정 가격으로 보지 않습니다.

왜 중요

별도 서버 구축 없이 상시 실행되는 Hermes Agent를 운영할 수 있는 관리형 선택지가 공식 프리뷰로 확인됐습니다. 공식 Docs와 repository는 Desktop에서 Hermes Cloud 계정으로 호스팅 인스턴스를 발견·연결하고, 로컬·원격·SSH 인스턴스와 함께 다루는 운영 흐름을 확인합니다.

우리 영향

기존 로컬·VPS·SSH 운영은 그대로 유지되며 Cloud 사용이 강제되지 않습니다. Cloud 인스턴스는 플랫폼 관리형으로 분류되어 Desktop의 전체 인스턴스 업데이트에서도 제외되고, 사용자가 직접 hermes update를 실행하는 대상이 아닙니다. 프리뷰 서비스이므로 실제 비용·지역·데이터 보존·가용성은 가입 시점 조건을 별도로 확인해야 합니다.

지금 할 일

X 글만으로 설치·릴리스 버전을 확정하거나 자동 업데이트하지 않습니다. 관리형 운영이 필요할 때만 공식 Cloud 페이지에서 프리뷰 조건과 실제 결제 예상액, 지원 지역, 데이터·보안 조건을 확인한 뒤 별도 시험 인스턴스로 평가합니다. 기존 self-hosted 환경에는 변경하지 않습니다.
