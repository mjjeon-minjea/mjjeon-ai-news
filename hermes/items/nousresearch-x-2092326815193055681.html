Hermes Agent MCP 커넥터 카탈로그, 일상 앱 연결 44개 확대

New in Hermes Agent: The built in MCP Connectors Catalog expanded to offer 44 new connections for apps you use every day, with easy one click setup in the Hermes Desktop App

핵심 요약

NousResearch는 공식 X 독립 원글에서 Hermes Agent의 내장 MCP 커넥터 카탈로그에 일상적으로 사용하는 앱용 신규 연결 44개가 추가됐으며 Hermes Desktop에서 한 번의 클릭으로 설정할 수 있다고 발표했습니다. 원문은 답글이나 리트윗이 아닌 원글이며 URL은 HTTP 200으로 확인했습니다. 공식 Docs는 Nous 검토 카탈로그의 원클릭 설치와 Desktop 제안 기능을, repository는 대규모 원격 MCP manifest 추가와 후속 보안·도구 범위 정리를 확인합니다. 다만 공식 Releases에는 이 발표와 연결된 새 태그가 아직 없습니다.

왜 중요

외부 업무 앱을 Hermes Agent에 연결하는 선택 폭과 Desktop 설정 편의가 크게 늘어난 운영 변경입니다. X의 수량 발표를 공식 Docs의 카탈로그 동작 및 repository의 실제 manifest 확대와 교차확인했으므로 meaningful change로 분류하지만, X 글은 설치 버전이나 배포 완료 범위를 확정하는 대표 출처로 사용하지 않습니다.

우리 영향

새 연결은 기본 비활성 상태이며 실제 사용 가능 여부는 설치된 Hermes backend와 Desktop이 해당 카탈로그 변경을 포함하는지에 따라 달라집니다. 항목별로 OAuth·API 키·외부 서버 권한 또는 설치 명령이 필요할 수 있고, 연결 후 노출되는 도구 범위가 달라지므로 source·transport·auth·권한과 도구 필터를 설치 전에 검토해야 합니다. 기존 설치의 자동 업데이트나 설정 변경은 발생하지 않습니다.

지금 할 일

X 글만으로 설치·릴리스 버전을 확정하거나 자동 업데이트하지 않습니다. 공식 Releases와 Docs에서 배포 여부를 확인한 뒤 Hermes의 MCP 카탈로그 또는 Desktop 화면에서 필요한 연결만 수동 선택하고, 각 manifest의 출처·실행 명령·인증 범위·기본 제외 도구를 검토해 최소 권한으로 설치합니다. MCP 항목은 자동 갱신되지 않으므로 공식 업데이트 후 필요한 경우에만 재설치합니다.
