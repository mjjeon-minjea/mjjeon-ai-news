Hermes Agent v0.22.3 공식 출시: 누적 변경을 안정 릴리스로 통합

Hermes Agent v0.22.3

게시 승인. 지정 후보 ID와 content_hash가 일치하고 공식 릴리스 원문의 제목·버전·발행 시각을 대조했다. 공식 릴리스·저장소·문서 URL은 리디렉션 후에도 동일한 공식 주소이며 모두 HTTP 200을 반환했다. Hermes 운영에 영향을 주는 안정 릴리스이므로 meaningful change와 대표 기사 자격을 인정한다. 조회된 저장소 Releases 요약에는 v0.22.2가 남아 있어 릴리스 상세와 다른 교차신호를 escalation 후보로만 표시하며, v0.22.3 공개 근거는 공식 릴리스 상세를 사용한다. 보안 취약점이나 breaking change는 이 공지만으로 단정하지 않는다.

핵심 요약

Nous Research가 Hermes Agent v0.22.3을 공식 패치 릴리스로 공개했다. v0.22.2 이후 약 620개 병합 PR을 CLI·설치 프로그램·Microsoft Store·Docker·Hermes Cloud용 안정 릴리스로 통합하며, MCP 진행 알림, 플러그인 OAuth 및 업데이트, CLI 화면 개선, 압축 후 플러그인 훅과 세션 자동 정리의 선택적 활성화 등이 포함됐다고 밝혔다. 상세 정리 노트는 v0.23.0에서 제공할 예정이며, 설치 프로그램으로 설치한 Desktop 앱은 이번 릴리스에서 변경 없이 다음 번들 릴리스를 기다린다.

왜 중요

단순 예고나 소셜 언급이 아니라 공식 버전 태그와 업데이트 채널 안내가 있는 안정 릴리스다. 도구 진행 표시, 플러그인 인증·갱신, 세션 보존 정책 등 실제 에이전트 운영에 영향을 주는 변경을 포함한다.

우리 영향

CLI와 Docker·Cloud 운영자는 새 안정 릴리스의 적용 여부를 검토할 수 있다. 세션 자동 정리가 다시 명시적 선택 방식이 된 점과 플러그인 인증·업데이트 흐름을 확인해야 하며, Microsoft Store와 설치 프로그램 기반 Desktop은 업데이트 경로가 다르므로 동일하게 취급하면 안 된다.

지금 할 일

공식 릴리스와 문서의 설치 채널별 업데이트 절차를 확인하고, 세션 보존·플러그인·MCP 동작을 검증한 뒤 승인된 절차로 적용 여부를 결정한다. 이번 뉴스 게시 작업에서는 Hermes 설치 버전을 변경하거나 자동 업데이트하지 않는다.
