Hermes Agent v0.23.3 안정판 공개…프롬프트 캐시·대화 압축 개선 통합

Hermes Agent v0.23.3

게시 승인: 제공된 후보와 공식 GitHub 릴리스의 제목·태그·변경 설명이 일치하고, 공식 문서의 저장소 연결 및 저장소의 최신 릴리스 링크로 출처를 교차 확인했다. 문서·저장소·후보 릴리스의 최종 URL과 HTTP 200을 확인했다. 기존 게시 비교 항목은 없으며 안정판 배포와 운영 동작 변경을 meaningful change로 판단한다. official/release 대표 후보로 적격이다. 보안 의존성 변경은 escalation 후보일 뿐이며 breaking change나 긴급 운영 변경은 확정하지 않는다.

핵심 요약

Nous Research가 v0.23.2 이후 약 370개 병합 PR을 묶은 Hermes Agent v0.23.3 패치 안정판을 공개했다. 공식 릴리스 설명은 프롬프트 캐시 수명주기 제어와 cache_ttl 기본값 auto, 압축 시 제외되는 도구 결과의 아카이브, 선제적 도구 결과 정리 기본 활성화, 첫 실행 설정 간소화, SQLite 저장 계층 분리 등을 이 기간의 변경으로 열거한다. 전체 정리본은 v0.24.0에서 제공할 예정이다. 본문상 릴리스 날짜는 11월 19일이며 GitHub 게시시각은 11월 20일 00:34:38 UTC다.

왜 중요

단순 예고가 아니라 CLI·Microsoft Store·Docker·Hermes Cloud를 위한 공식 안정판 배포다. 캐시 유지와 컨텍스트 정리, 저장 계층 변경이 장시간 에이전트 운영에 관련되므로 운영자가 확인할 실질적인 업데이트로 판단한다.

우리 영향

공식 설명상 긴 도구 실행 중 캐시 유지, 유휴 대화 압축, 도구 결과 보존·정리 동작이 달라질 수 있다. CLI는 hermes update, Microsoft Store는 Store 업데이트, Docker·Hermes Cloud는 공식 stable 또는 latest 이미지가 안내됐다. 설치형 데스크톱 앱의 .exe·.dmg 번들은 이번 릴리스에서 변경되지 않으며 다음 번들 릴리스에서 갱신된다. 실제 비용 절감률이나 성능 향상 폭은 확인되지 않았다.

지금 할 일

공식 릴리스 원문을 기준으로 게시한다. 운영 환경의 자동 업데이트나 컨테이너 변경은 실행하지 않는다. 도입 검토 시 캐시·압축·세션 저장 동작을 사전 검증하고 배포 채널별 적용 범위를 구분한다. oauthlib·opentelemetry·tornado 보안 의존성 갱신은 escalation 후보로만 표시하며 취약점의 심각도나 긴급 패치 필요성을 단정하지 않는다. 상세 변경과 호환성은 예고된 v0.24.0 정리본에서도 재확인한다.
