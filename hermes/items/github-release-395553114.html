Hermes Agent v0.21.5(v2026.9.24) 패치 릴리스

Hermes Agent v0.21.5 (v2026.9.24)

공식 패치 확인 · Releases·Docs·repository 교차확인 · 플러그인·Connectors·Gateway 권한 및 호환성은 에스컬레이션 후보 · 명시적 breaking 근거 없음

핵심 요약

v0.21.4 이후 약 460개 병합 PR을 묶은 공식 안정 태그입니다. Desktop 플러그인 SDK와 Simple/Advanced 모드, MCP 탭을 대체하는 Connectors 화면, 설치 플러그인의 도구·스킬 즉시 반영, 다국어·RTL/LTR 지원, 사용자 정의 모델, 프로필별 Gateway 제어, CLI·TUI live dock, webhook 세션 미러링, hosted Bot Screen과 신규 모델·통합·성능 개선이 포함됐습니다.

왜 중요

플러그인과 Connectors가 Desktop의 작성기·세션 목록·설정·프로필·외부 도구까지 확장되고, 설치 직후 열린 채팅에 도구와 스킬이 반영되는 등 실제 운영·권한 경계가 넓어집니다. 프로필별 시작·중지·재시작과 gateway.standalone도 다중 프로필 운영 방식에 직접 영향을 줍니다.

우리 영향

Docker·Hermes Cloud·호스팅 배포의 새 기준 태그이며 Desktop, Gateway multiplexer, 플러그인, Connectors, CLI·TUI, webhook과 hosted Bot Screen 경로가 함께 바뀝니다. 1,610개 비병합 커밋과 4,828개 변경 파일을 포함하고 상세 정리본은 v0.22.0으로 미뤄졌으므로 기존 플러그인 권한·세션 전달·프로필 격리·이미지 호환성 회귀 위험을 별도로 검증해야 합니다.

지금 할 일

자동 업데이트하지 않습니다. 현재 설치 유형·버전과 백업·롤백 경로를 확인한 뒤 별도 시험 환경에서 플러그인 sandbox·event bridge, Connectors 권한과 열린 채팅 반영, 프로필별 Gateway 제어와 gateway.standalone, webhook 세션 미러링, hosted Bot Screen 이미지 및 기존 Desktop·CLI·TUI 동작을 회귀검증하고 단계적으로 적용합니다.
