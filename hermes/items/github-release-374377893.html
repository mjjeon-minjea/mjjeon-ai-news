Hermes Agent v0.20.5(v2026.8.19) 패치 릴리스

Hermes Agent v0.20.5 (v2026.8.19)

공식 패치 확인: 핵심 운영 경로 회귀시험 후 단계적 적용

핵심 요약

v0.20.4 이후 약 323개 병합 PR과 약 746개 커밋을 묶은 공식 패치 릴리스다. 봇 모드 그룹 대화 스레드와 파일 첨부, 키 없이 이용하는 웹 검색 계층, CLI 모델 선택기와 명령 팔레트, 실행 정체 방지, 업데이트 영수증과 플릿 사전 계획 검증, worktree 관리, cron 영구 메모리와 작업별 추론 강도 설정 등이 포함됐다.

왜 중요

Docker 이미지·호스팅 배포·신규 설치에 쓰이는 안정 태그이며, 봇·웹 검색·CLI·업데이트·cron처럼 실제 Hermes Agent 운영 경로가 폭넓게 달라진다. 특히 키 없는 공급자 순환과 업데이트 검증 기능은 설치 직후의 사용성과 플릿 운영 점검 방식에 직접 영향을 준다.

우리 영향

그룹 대화와 첨부 처리, 무키 웹 검색, CLI 조작, 장시간 실행 감시, 업데이트 확인, cron 문맥 유지가 개선될 수 있다. 다만 약 1,250개 파일에 걸친 큰 패치이고 전체 정리본은 v0.21.0에서 제공될 예정이므로, 현재 환경의 봇·공급자·업데이트·cron 동작을 별도 시험해야 한다.

지금 할 일

운영 환경에 자동 적용하지 말고 별도 시험 환경에서 hermes update 사전 계획과 영수증, 봇 그룹 대화·첨부, 무키 웹 검색 장애 전환, CLI, 장시간 실행 정체 방지, cron 메모리·추론 설정을 회귀검증한 뒤 단계적으로 적용한다.
