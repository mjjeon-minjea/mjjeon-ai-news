Hermes Agent v0.23.1: 플러그인 최신 카탈로그를 못 읽던 문제 수정

Hermes Agent v0.23.1

게시 적합 — 공식 안정 릴리스의 플러그인 설치 동작 수정이므로 의미 있는 운영 변경으로 판단한다. 제공된 후보 스냅샷으로 내용을 검토하고 공식 릴리스 URL의 리디렉션 후 최종 HTTP 200을 확인했다. 보안·breaking change를 임의로 확정하거나 자동 업데이트하지 않는다.

핵심 요약

Hermes Agent v0.23.1 안정 패치는 플러그인 카탈로그 응답 허용량을 2 MiB에서 16 MiB로 늘렸다. 11월 9일 카탈로그 배포 뒤 크기 제한을 초과하면서 설치 명령이 알림 없이 내장 카탈로그로 되돌아가던 문제를 수정한다. 최신 플러그인 검색, 현재 버전 핀과 제거 항목 반영을 복구하며, v0.23.0 이하는 업데이트 전까지 기존 동작이 지속된다. v0.23.0 이후 약 618개 병합 PR을 묶은 배포이고, 이 구간의 전체 정리 노트는 v0.24.0에서 제공할 예정이다.

왜 중요

설치 명령이 성공해도 오래된 카탈로그를 사용하면 새 플러그인을 찾지 못하거나 과거에 고정된 버전을 설치하고 최신 제거 표시를 놓칠 수 있다. 단순 버전 표기 변경이 아니라 플러그인 설치 입력원의 최신성을 복구하는 운영상 의미 있는 수정이다.

우리 영향

영향 대상은 플러그인을 설치하는 CLI·Microsoft Store·Docker·Hermes Cloud 사용자다. 설치형 Desktop 앱은 이번 릴리스에서 변경되지 않으며 다음 번들 릴리스에서 업데이트된다. 이 뉴스는 공식 배포 버전 안내이며, 운영 중인 설치본이 v0.23.1로 바뀌었다는 뜻은 아니다. 릴리스 본문의 날짜는 11월 9일이고 GitHub 발행 메타데이터는 11월 10일 UTC로 구분한다.

지금 할 일

플러그인 설치 사용자라면 업데이트 필요성을 우선 검토한다. 공식 안내는 CLI의 hermes update 또는 설치 프로그램 재실행, Microsoft Store 자동 업데이트, Docker·Cloud의 nousresearch/hermes-agent:stable 또는 :latest 사용이다. 실제 운영 업데이트는 설치 방식과 영향 범위를 확인하고 별도 승인 후 진행하며, 이번 게시 작업에서는 설치본이나 컨테이너를 변경하지 않는다. 미정리된 기능 전체는 v0.24.0 정리 노트에서 다시 확인한다.
