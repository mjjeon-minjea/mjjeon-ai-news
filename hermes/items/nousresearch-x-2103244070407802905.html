핵심 요약

NousResearch는 공식 X 독립 원글에서 Hermes Agent 웹 검색에 Perplexity Fast Search를 도입하고 모든 Nous Portal 등급에 무료로 제공한다고 발표했습니다. 답글이나 리트윗이 아닌 원글이며 원문 URL은 정상 조회됐습니다. 공식 저장소의 후속 main 커밋은 Nous 관리형 검색을 Perplexity로 라우팅하고 문서·상태 표기에서 특정 공급자명을 숨기며, 본문 추출은 Firecrawl에 유지하는 구현을 확인합니다. 최신 공식 v0.21.5 릴리스는 이 커밋보다 먼저 태그되어 이번 변경의 배포 버전을 확정하지 않습니다.

왜 중요

Nous Portal을 사용하는 Hermes Agent의 웹 검색 속도와 별도 검색 API 비용 부담을 줄일 수 있는 실제 운영 변경입니다. 다만 현재 공개 Docs에는 웹 검색을 Firecrawl 기반 유료 Tool Gateway로 설명하는 내용이 남아 있어, X의 무료 범위와 실제 배포 시점은 교차신호 에스컬레이션 후보로 다뤄야 합니다.

우리 영향

Nous 관리형 웹 검색을 선택한 환경은 Perplexity Fast Search 경로를 사용하고, 페이지 추출은 기존 Firecrawl 경로를 유지합니다. 직접 Perplexity 키를 지정한 구성은 직접 키 경로가 우선하며, 최신 태그 v0.21.5에 이 변경이 포함됐다고 단정할 수 없습니다. 현재 설치 버전·Gateway·프로필은 자동으로 변경되지 않습니다.

지금 할 일

X 글만으로 설치·릴리스 버전을 확정하거나 자동 업데이트하지 않습니다. 이 구현을 포함하는 공식 Release와 갱신된 Docs가 게시된 뒤 Nous Portal 계정의 실제 이용 자격·과금 표시를 확인하고, 별도 시험 환경에서 검색 품질·지연·실패 전환·추출 경로를 검증한 후 적용합니다.
