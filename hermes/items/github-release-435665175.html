Hermes Agent v0.23.0 공개: 브라우저 작업공간·단일 게이트웨이·MCP 비용 한도

Hermes Agent v0.23.0 — The Hearth Release

공식 릴리스 원문과 리디렉션 후 동일한 최종 URL의 HTTP 200을 확인했다. 제공된 후보 snapshot 기준 신규 주요 업데이트로 판단해 게시 승인한다. 보안·breaking 변경은 escalation 후보이며 운영 환경 반영 승인과는 구분한다. 설치된 버전이나 성능 개선의 현장 검증을 완료했다는 의미는 아니다.

핵심 요약

Nous Research가 Hermes Agent v0.23.0 ‘The Hearth Release’를 정식 공개했다. 공식 릴리스 노트에 따르면 자체 게이트웨이에서 Desktop 작업공간을 브라우저로 제공하는 Webapp이 추가됐으며 기본값은 비활성이다. CLI·TUI·Desktop·편집기·봇·cron은 단일 게이트웨이를 통해 세션의 큐와 기록을 공유한다. 터미널 인라인 이미지와 /rewind, 다중 게이트웨이 연결, 그룹채팅 라우팅, 선택형 플러그인 자동 업데이트, 유료 MCP 도구의 호출 가격 표시·채팅별 지출 한도가 포함됐다. 장시간 실행 게이트웨이의 메모리·응답성과 cron 프롬프트 캐시도 개선했다고 설명한다. v0.22.1~v0.22.7 패치 내용도 통합 정리했다.

왜 중요

단순 버전 표기 변경이 아니라 여러 접속 화면의 세션 소유권, 웹 접근 방식, 장기 실행 안정성과 유료 도구 승인 절차를 함께 바꾸는 운영상 주요 릴리스다. 공식 릴리스에서 신규 기능과 마이그레이션 주의사항을 직접 확인할 수 있어 대표 공식 업데이트로 게시할 가치가 있다.

우리 영향

릴리스 노트 기준으로 기존 내장 browser_* 도구가 제거되고 브라우저 자동화는 browser_exec로 전환된다. MCP 서버 실행 명령은 hermes mcp serve에서 hermes mcp-serve로 변경해야 한다. Desktop은 Electron 44 전환으로 macOS 11·12와 32비트 Windows 지원을 종료한다. Webapp과 플러그인 자동 업데이트는 기본 비활성이며, 유료 MCP 도구는 선언된 호출 비용과 채팅 한도 초과 여부를 승인 화면에 표시한다. 비밀값 마스킹·승인 게이트·네트워크 경계 보강도 발표됐으나 실제 운영 환경 적용 효과는 별도 검증 대상이다.

지금 할 일

업데이트 전 프롬프트·스킬·도구 목록의 기존 브라우저 도구명, MCP 클라이언트 실행 명령과 Desktop OS 호환성을 점검한다. Webapp 공개 접근은 인증·노출 범위를 별도 검토하고, 유료 MCP 도구의 비용 선언과 채팅별 한도를 확인한다. 보안 및 호환성 변경은 escalation 후보로만 표시하며 자동 업데이트·게이트웨이 재시작·설정 변경은 수행하지 않는다.
