NousResearch, Hermes Agent의 Microsoft Store 배포 안내

Hermes Agent is now live (and featured) in the @Microsoft Store for seamless one-click install. More updates for the Windows ecosystem coming soon! https://t.co/lPH4snZ2L3

게시: NousResearch 본계정의 원글로 확인했으며 답글·리트윗 표시는 없고 작성자·게시 시각·본문이 후보 raw와 일치한다. Hermes Agent의 Windows 배포 경로 변화만 meaningful change로 인정한다. 공식 Docs·repository·Releases와 교차검증한 보조 신호이며 대표 기사로 선정하지 않는다. 공식 Docs 인덱스와 저장소는 리다이렉트 후 최종 공식 URL 및 HTTP 200을 확인했다. Store 추천 노출과 향후 Windows 업데이트 예고는 미확정 주장으로 유지한다.

핵심 요약

NousResearch는 Hermes Agent가 Microsoft Store에 등록되어 원클릭 설치를 지원한다고 발표했다. 원글의 스토어 추천 노출 주장은 X 발표 내용으로만 구분한다. 공식 설치 문서와 Windows 가이드는 Store 패키지의 별도 배포·업데이트 경로를 설명한다. 공식 v0.21.6 릴리스는 Microsoft Store가 기존 빌드를 유지한다고 명시하므로, 이 게시물을 새 Store 버전 출시로 해석하지 않는다.

왜 중요

Windows 사용자의 설치 진입 경로가 확장되는 운영상 변화다. Store 설치, App Installer 사이드로드, 소스 설치는 업데이트 책임 주체가 다르므로 신규 도입 시 배포 방식과 업데이트 경로를 구분해야 한다.

우리 영향

Windows 신규 도입에서는 Store 배포 경로를 검토할 수 있다. 공식 Windows 문서에 따르면 Store 패키지는 Store 업데이트를 사용하며 사이드로드 피드를 사용하지 않는다. 기존 Linux·Docker 운영 환경의 즉시 변경이나 자동 업데이트를 요구하는 발표는 아니다. Store의 실제 설치 버전과 추천 노출 상태는 이번 검토에서 확정하지 않았다.

지금 할 일

공식 설치 문서 https://hermes-agent.nousresearch.com/docs/getting-started/installation 및 Windows 가이드 https://hermes-agent.nousresearch.com/docs/user-guide/windows-native 를 기준으로 도입 방식을 확인한다. 공식 저장소 https://github.com/NousResearch/hermes-agent 와 릴리스 https://github.com/NousResearch/hermes-agent/releases/tag/v0.21.6 를 교차검증했다. X 발표만으로 설치·릴리스 버전을 확정하거나 자동 업데이트하지 않는다. 보안·breaking·교차신호 조건은 별도 escalation 후보로만 표시한다.
