Hermes Advanced Delegation: 하위 작업별 모델·프로필 경로 선택

With the new Advanced Delegation modes plugin, Hermes Agent's orchestrator can now pick a different model or profile for each subagent from routes you set up. The right model or profile for every job. https://t.co/qu72GjRqin https://t.co/LMLgBEBuuF

게시: Hermes Agent 운영 변경을 공식 문서·릴리스·저장소로 교차검증한 X 보조 신호다. 직접 조회한 주 게시물은 NousResearch 작성 원글로 표시되고 답글은 별도 댓글로 구분되며, 리트윗 표시는 없다. 공식 문서 색인과 Hermes 저장소는 리다이렉트 후 동일한 공식 URL에서 HTTP 200을 확인했다. 대표 공식 업데이트로 승격하지 않으며 X만으로 버전이나 설치 상태를 확정하지 않는다. 프로필 권한 공유와 교차신호는 escalation 후보일 뿐, 보안 취약점·breaking change 확정이나 자동 조치의 근거가 아니다.

핵심 요약

NousResearch가 원글에서 Advanced Delegation 플러그인의 작업별 모델·프로필 선택 기능을 소개했다. 공식 문서와 고정 커밋의 공식 플러그인 저장소는 model_map과 profile_routes를 서로 별도 모드로 제공하고, 운영자가 미리 허용한 경로만 선택하도록 한다고 설명한다. 공식 v0.22.5 릴리스에서도 플러그형 위임 백엔드를 확인했으며, 문서와 저장소가 명시한 최소 요구 버전은 Hermes 0.22.5다. 이는 기능 소개 보조 신호이며 새로운 버전 출시나 현재 설치 버전의 확인을 뜻하지 않는다.

왜 중요

하위 작업마다 같은 모델을 쓰는 방식에서 벗어나 작업 성격에 맞춘 모델 또는 기존 프로필을 선택할 수 있는 실질적인 운영 변경이다. 근거는 공식 문서 https://hermes-agent.nousresearch.com/docs/plugins/advanced-delegation, 공식 릴리스 https://github.com/NousResearch/hermes-agent/releases/tag/v0.22.5, 공식 저장소의 검토된 커밋 https://github.com/NousResearch/hermes-official-plugins/blob/e404b6816b20237a82f6fbe2749b5a576cf75dba/advanced-delegation/README.md 에서 교차확인했다.

우리 영향

model_map에서는 경로별 모델·제공자를, profile_routes에서는 대상 프로필의 모델·자격증명·스킬·실행 정책을 사용한다. 두 모드에서는 기존 delegation.model/provider 대신 모드의 기본 경로 또는 부모 모델이 적용되므로 비용·권한·기본 동작을 따로 검토해야 한다. 경로 설정 변경은 새 세션에 반영하는 것이 기본이며, 현재 대화에 즉시 적용하면 프롬프트 캐시가 끊길 수 있다. 비용 절감 효과나 현재 환경의 호환성은 실측하지 않았다.

지금 할 일

자동 설치·업데이트·설정 변경은 하지 않는다. 도입 검토 시 공식 문서와 릴리스 기준으로 설치 환경의 호환성을 확인하고, 허용할 모델·프로필과 기본 경로를 최소 범위로 정한다. 프로필 간 권한 사용은 보안 escalation 후보로만 표시하며, 경로별 호출 단가·월 예상 비용·한도를 산정하고 승인받은 뒤 별도 검증한다.
