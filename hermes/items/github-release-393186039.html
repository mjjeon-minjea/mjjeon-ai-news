Hermes Agent v0.21.4(v2026.9.21) 패치 릴리스

Hermes Agent v0.21.4 (v2026.9.21)

공식 패치 확인 · Releases·Docs·repository 교차확인 · Gateway·권한·보안 경계 변경은 에스컬레이션 후보 · 명시적 breaking 근거 없음

핵심 요약

v0.21.3 이후 약 1,800개 병합 PR을 묶은 공식 안정 태그입니다. 호스트 전체 Gateway 단일 실행 잠금과 Desktop의 기존 backend 연결, 통합 커넥터 설정, CLI stream-json 출력, skills.auto_load, 미승인 DM 거절, MCP 탐색 동시성 제한, 세션 검색·저널 모드, 플러그인 카탈로그 확대와 profile·cron·Desktop·state.db 수정이 포함됐습니다.

왜 중요

Gateway 중복 실행 방지와 profile 격리, cron 및 state.db 안정성 개선은 다중 프로필 운영에 직접 영향을 줍니다. 동시에 스킬 자동 로드, 미승인 DM 처리, 커넥터·MCP 및 플러그인 동작처럼 권한과 보안 경계에 닿는 변경이 있어 적용 전 검증이 필요합니다.

우리 영향

공식 태그는 Docker 이미지와 Hermes Cloud·호스팅 배포의 기준이 됩니다. 다만 v0.21.3 이후 5,071개 비병합 커밋과 5,169개 변경 파일을 포함하고 상세 정리본은 v0.22.0으로 미뤄졌으므로, Gateway 단일 실행·Desktop 연결·profile 격리·cron·커넥터·MCP·플러그인·state.db 경로의 호환성과 보안을 시험해야 합니다.

지금 할 일

자동 업데이트하지 않습니다. 현재 설치 유형·버전과 백업·롤백 경로를 확인한 뒤 별도 시험 환경에서 Gateway 단일 실행과 Desktop 연결, profile 격리, cron, skills.auto_load, 미승인 DM, 커넥터·MCP·플러그인, state.db 동작을 회귀검증하고 단계적으로 적용합니다.
