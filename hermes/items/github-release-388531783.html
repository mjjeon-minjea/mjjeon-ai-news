Hermes Agent v0.21.3(v2026.9.14) 패치 릴리스

Hermes Agent v0.21.3 (v2026.9.14)

공식 패치 확인 · Releases·Docs·repository URL 교차확인 · 인증 세션 및 Cloud 자동 갱신 영향은 에스컬레이션 후보 · 명시적 breaking 근거 없음

핵심 요약

v0.21.2 이후 약 338개 병합 PR을 묶은 공식 패치 릴리스입니다. Remote Desktop과 Hermes Cloud에서 동시에 발생한 토큰 갱신 요청을 병합해 세션이 취소되는 문제를 막고, 느린 인증 공급자가 상태 API를 멈추지 않도록 개선했습니다. 장시간 실행 프로세스의 중복 state.db writer handle 누수도 수정했습니다.

왜 중요

Desktop 절전 해제나 새로고침 집중 시 원격 Gateway 로그인 세션 전체가 만료될 수 있던 문제와 장기 실행 시 SessionDB handle이 누적되던 문제를 직접 해결합니다. 특히 최신 릴리스 태그로 자동 갱신되는 Hermes Cloud 에이전트의 원격 접속 안정성에 중요합니다.

우리 영향

Remote Desktop·Cloud 사용자는 인증 세션 유지와 Gateway 상태 응답 안정성이 개선되고, Gateway·Desktop backend·ACP·CLI의 SessionDB handle 중복 생성이 줄어듭니다. 다만 v0.21.2 이후 1,036개 비병합 커밋과 2,642개 변경 파일을 포함하며 일부 변경은 릴리스 노트에서 의도적으로 생략됐으므로 기존 인증·Gateway·Desktop·CLI 경로의 회귀검증이 필요합니다.

지금 할 일

self-hosted 운영 환경은 자동 업데이트하지 않습니다. 현재 설치 유형·버전과 백업·롤백 경로를 확인한 뒤 별도 시험 환경에서 원격 Desktop 로그인 갱신, Gateway 상태 응답, SessionDB 장시간 실행, ACP·CLI 동작을 검증하고 단계적으로 적용합니다. Hermes Cloud의 자동 갱신 대상은 세션 유지와 서비스 상태를 별도 확인합니다.
