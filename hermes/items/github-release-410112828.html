Hermes Agent v0.21.7: 공식 소스 설치 업데이트가 안정 릴리스 기준으로 전환

Hermes Agent v0.21.7

지정 ID와 content_hash가 일치하는 후보만 검토했다. NousResearch 공식 GitHub 릴리스 원문을 직접 읽고, 리다이렉트 후 최종 URL이 동일한 공식 릴리스 주소이며 HTTP 200임을 확인했다. 실제 업데이트 정책 및 세션 재개 수정이 있으므로 meaningful change인 공식 대표 기사로 게시한다. 보안 취약점이나 breaking change는 확인된 사실로 단정하지 않으며, 보안·breaking·교차신호 조건은 추가 근거가 있을 때 escalation 후보로만 취급한다.

핵심 요약

NousResearch가 정식 패치 릴리스 v0.21.7을 공개했다. 공식 저장소의 소스 설치는 이제 main의 모든 커밋 대신 최신 공개 vX.Y.Z 릴리스를 따라 업데이트하며, 이미 그 릴리스보다 앞선 설치는 되돌리지 않는다. 데스크톱 소스 설치에는 안정 릴리스·모든 커밋 채널 선택이 추가됐다. 재개된 CLI·게이트웨이 세션에서 서명된 thinking 재생과 Bedrock Converse reasoning 호환성을 수정하고, 일부 방화벽 환경의 업데이트 실패 및 GitHub 제한 오류 처리를 개선했다. 이 기간의 전체 정리 릴리스 노트는 v0.22.0에 제공할 예정이라고 명시했다.

왜 중요

업데이트가 추적하는 기준이 커밋 단위에서 릴리스 단위로 바뀌므로, 공식 소스 설치 운영자는 배포 주기와 업데이트 채널을 명시적으로 관리해야 한다. 세션 재개 시 reasoning 호환성 수정도 장시간 CLI·게이트웨이 운영의 연속성과 관련된 실질적 변경이다.

우리 영향

업데이트 채널 변경의 대상은 공식 저장소의 소스 설치다. 포크·미러는 main 추적을 유지하고, Store·MSIX·번들 데스크톱 설치의 동작은 변경되지 않는다. 최신 공개 릴리스보다 앞선 설치는 유지된다. 릴리스 공개 사실은 현재 운영 환경의 설치 버전이나 적용 완료를 의미하지 않는다.

지금 할 일

소스 설치 운영자는 현재 업데이트 채널과 릴리스 적용 계획을 확인한다. 커밋 단위 추적이 필요한 경우 공식 안내의 hermes update --set-channel main을 별도 승인·변경관리 대상으로 검토한다. 설치·자동 업데이트·Docker 변경은 이번 뉴스 게시에서 수행하지 않는다. 업데이트 정책 변경은 운영 검토용 escalation 후보로만 표시한다.
