Hermes Agent v0.20.2 패치 릴리스

Hermes Agent v0.20.2 (2026.8.16)

공식 패치 확인·검증 후 적용

핵심 요약

v0.20.1 이후 변경을 묶은 공식 안정 태그다. 데스크톱 연결 관리와 MCP 상태 확인, CLI 호환성·입력 처리, 게이트웨이 모델 경로·루프 완료·텔레그램 DM 주제, Claude 프롬프트 캐싱, 크론·인증·설치 안정성 개선이 포함됐다.

왜 중요

데스크톱·CLI·게이트웨이·크론·인증·설치 경로를 함께 손본 대규모 패치 묶음이라 Hermes 운영 안정성과 배포 호환성에 직접 영향을 준다.

우리 영향

기존 설치는 공식 업데이트 명령을 사용할 수 있지만 전체 상세 릴리스 노트는 v0.21.0에서 제공될 예정이므로, 현재 운영 환경의 프로필·게이트웨이·크론·메신저 연동 회귀검증이 필요하다.

지금 할 일

자동 업데이트하지 말고 현재 배포 구조와 백업·롤백 경로를 확인한 뒤 스테이징에서 업데이트, 게이트웨이 연결, 크론, 인증, 텔레그램 동작을 검증하고 운영 반영 여부를 결정한다.
