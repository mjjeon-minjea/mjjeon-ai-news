Hermes Agent v0.22.0: 안정 릴리스 기본값·단일 게이트웨이·세션 보존 정책 변경

Hermes Agent v0.22.0 — The Threshold Release

지정 ID와 content_hash가 일치하는 GitHub 공식 릴리스 후보를 직접 검토했다. 원문 제목과 게시 시각을 보존했으며, 공식 릴리스 본문을 조회하고 리디렉션 후 최종 공식 URL의 HTTP 200을 확인했다. 업데이트 채널·게이트웨이·세션 정책에 의미 있는 운영 변경이 있어 official/release로 게시하고 대표 기사 자격을 부여한다. 런타임·게이트웨이·세션·플러그인 호환성 변화는 breaking escalation 후보로만 표시하며, 설치 버전 확인이나 자동 업데이트는 수행하지 않는다.

핵심 요약

NousResearch가 Hermes Agent v0.22.0 공식 릴리스를 공개했다. 공식 릴리스 설명에 따르면 소스 설치의 기본 업데이트 경로가 main 커밋 추적에서 검증된 SemVer 안정 릴리스로 바뀌고, 통합 패키지 관리자 hermes pm은 새 실행 환경 검증 후 전환한다. 여러 프로필은 머신당 하나의 메시징 게이트웨이와 데스크톱 백엔드를 공유하며, 로컬 모델 실행과 앱 커넥터도 추가됐다. 운영상 중요한 변경은 관리형 설치의 Python 3.14 전환, 유휴·일일 세션 초기화 폐지, 종료 후 90일간 비활성인 세션의 기본 자동 삭제다.

왜 중요

단순 모델 목록 확대가 아니라 업데이트 채널, 실행 환경, 다중 프로필 프로세스 구조와 세션 보존 기본값이 함께 바뀌는 운영 변경이다. 안정 릴리스 추적과 검증 후 환경 전환은 배포 실패 위험을 줄이는 방향이지만, 기존 프로필·플러그인·세션 설정의 호환성을 별도로 확인해야 한다.

우리 영향

기존 프로필별 게이트웨이는 업데이트 시 충돌이 없으면 통합 구조로 마이그레이션된다. session_reset의 idle/daily 모드는 폐지되고 sessions.auto_prune은 기본 활성화되며, 고정되거나 열린 세션은 삭제 대상에서 제외된다. 관리형 설치에서 Python 3.14를 사용하므로 KittenTTS는 이용할 수 없고, 메모리 제공자 일부는 카탈로그 플러그인으로 이동한다. 이는 공식 발표 내용이며 현재 운영 설치에 실제 적용됐다는 뜻은 아니다.

지금 할 일

뉴스만 게시하고 운영 Hermes를 자동 업데이트하거나 게이트웨이를 변경하지 않는다. 적용을 검토할 때는 세션 보존 요구, 자동 삭제 설정, 프로필별 봇 라우팅·인증 격리, Python 3.14 및 플러그인 호환성을 먼저 확인한다. 보안·breaking 관련 변경은 escalation 후보로만 표시하고, 실제 마이그레이션과 설치 변경은 별도 승인 후 검증한다.
