Hermes Agent v0.22.0 정식 공개: 안정 릴리스 기본값과 설치·프로필 운영 변화

Hermes Agent v0.22.0 — The Threshold Release

게시 승인: 지정 candidate ID와 content_hash가 정확히 일치하고 raw의 draft와 prerelease가 모두 false인 공식 릴리스다. 원문 제목과 공개 시각을 보존했다. 공식 릴리스·Docs·repository를 web_extract로 직접 조회했으며, 지정 read-only GET으로 세 URL의 리다이렉트 후 최종 공식 URL과 HTTP 200을 확인했다. 설치·업데이트 정책과 프로필 운영에 의미 있는 변경이 있어 공식 대표 후보로 적합하다. raw 공개 시각과 본문의 Release Date 표기가 달라 날짜는 published_at을 기준으로 한다. 설치·릴리스 버전은 공식 릴리스 근거로만 판단하며 자동 업데이트는 하지 않는다.

핵심 요약

Nous Research가 Hermes Agent v0.22.0 정식 릴리스를 공개했다. 릴리스 설명은 검증된 SemVer 안정 릴리스를 기본 설치 대상으로 삼는 정책, 데스크톱 첫 실행 안내와 무료 체험 모델, 원클릭 llama.cpp 로컬 런타임, 프로필 운영의 백엔드·게이트웨이 구조 변화를 주요 내용으로 제시한다. v0.21.1~v0.21.7 패치 내용도 함께 정리한다.

왜 중요

단순 홍보가 아니라 설치·업데이트 대상 선택과 로컬 모델 실행, 여러 프로필의 운영 방식에 영향을 줄 수 있는 공식 릴리스다. 안정 릴리스 기본값은 운영 환경에서 최신 개발 코드와 검증된 배포 버전을 구분하는 기준이 된다.

우리 영향

기존 운영자는 업데이트 경로와 프로필별 게이트웨이 동작, 플러그인 호환성을 별도 점검할 필요가 있다. 첫 실행 무료 체험은 릴리스 설명상 OS 사용자당 한 번이며, 이후 사용 비용이나 기존 운영 환경의 무료 전환을 의미하지 않는다. 백엔드·게이트웨이 구조 변경에 따른 breaking 가능성은 escalation 후보로만 표시한다.

지금 할 일

공식 릴리스 기사로 게시한다. 실제 설치 버전 변경과 컨테이너·게이트웨이 재시작은 수행하지 않는다. 운영 적용은 공식 업데이트 문서와 환경별 호환성 확인을 거쳐 별도 승인하며, 보안·breaking·교차신호 조건은 escalation 후보로만 다룬다.
