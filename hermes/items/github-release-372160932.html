Hermes Agent v0.20.4(2026.8.18) 패치 릴리스

Hermes Agent v0.20.4 (2026.8.18)

에스컬레이션 후보: 보안 검사·호환성 검토 후 단계적 적용

핵심 요약

v0.20.3 이후 약 74개 병합 PR을 묶은 공식 패치 릴리스다. 데스크톱 화면 개선, 봇 모드 안정화, 스킬 설치 시 NVIDIA SkillEvaluator 1단계 자문 검사, cron 미디어 전송 보강, SessionDB 동시성 수정, 업데이트 상태 표시 개선이 포함됐다.

왜 중요

Docker·호스팅·신규 설치에 쓰이는 안정 태그이며, 봇·cron·세션 데이터베이스·업데이트 경로처럼 실제 운영에 직접 닿는 변경 범위가 넓다. 스킬 설치의 라이선스·보안 검사 기능도 추가되어 운영 정책과의 대조가 필요하다.

우리 영향

데스크톱과 봇 그룹 대화의 사용성·안정성, cron 첨부 전송과 누락 실행 확인, SessionDB 경합 완화가 기대된다. 다만 약 146개 커밋과 약 265개 파일을 포함한 큰 패치이므로 현재 배포 방식·스킬 설치 정책·봇 및 cron 회귀 여부를 사전 시험해야 한다.

지금 할 일

운영 환경에 자동 적용하지 말고 별도 시험 환경에서 업데이트·봇 모드·cron 첨부·SessionDB·스킬 검사 경로를 검증한 뒤 단계적으로 적용한다. 보안 검사와 호환성 영향은 별도 확인 대상으로 에스컬레이션한다.
