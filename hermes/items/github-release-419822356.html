Hermes Agent v0.22.4: 플러그인 동의·WhatsApp 재연결·프로필 승인 표시 수정

Hermes Agent v0.22.4

게시 적합: 지정 ID·hash가 일치하는 공식 정식 릴리스이며 구체적인 운영 변경이 확인되어 meaningful change로 판단한다. 대표 기사로 사용할 수 있다. 보안 검토 항목은 escalation 후보로만 남기고 자동 조치하지 않는다.

핵심 요약

공식 v0.22.4 패치는 설치할 의존성이 없는 플러그인의 빈 동의 창을 생략하고, 대시보드에서 로그아웃한 WhatsApp 계정을 다시 연결하는 문제를 수정했다. 데스크톱의 불필요한 추천 버튼을 제거하고 승인 모드 표시를 활성 프로필과 일치시켰으며, 느린 저장장치에서 릴리스 빌드 사전 검증 시간을 늘렸다. 데스크톱 플러그인 검토에서는 prototype 쓰기를 자동 린트 대신 사람이 점검하도록 변경했다.

왜 중요

단순 홍보가 아니라 플러그인 활성화, 메시징 계정 재연결, 프로필별 승인 모드 확인에 직접 영향을 주는 공식 운영 개선이다. 공식 릴리스 원문을 읽고 공식 문서 색인·저장소와 출처를 대조했으며, 세 공식 URL 모두 리디렉션 후 동일한 공식 주소와 HTTP 200을 확인했다.

우리 영향

플러그인과 WhatsApp 대시보드를 사용하는 운영자는 불필요한 동의 단계와 재연결 오류 감소를 기대할 수 있다. 데스크톱 승인 모드 표시 수정은 실제 권한 정책 변경으로 확대 해석하지 않는다. 릴리스 안내상 설치 파일로 설치한 데스크톱 앱은 이번에 변경되지 않으며 다음 번들 릴리스에서 갱신된다.

지금 할 일

현재 설치 방식과 버전을 확인한 뒤 별도 승인 절차로 업데이트를 검토하고, 적용 시 플러그인 활성화·WhatsApp 재연결·프로필 승인 모드 표시를 점검한다. 공식 안내는 CLI에 hermes update, Microsoft Store 앱에 Store 업데이트, Docker·Hermes Cloud에 공식 stable 또는 latest 이미지를 제시한다. 이번 뉴스 게시로 설치나 자동 업데이트를 수행하지 않는다. prototype 쓰기 자동 린트 제외는 보안 검토 escalation 후보로만 표시하며 취약점이나 breaking change로 확정하지 않는다.
