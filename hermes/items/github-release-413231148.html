Hermes Agent v0.22.1 공개: 압축 후 스킬 유지·MCP 제한시간 수정과 한국어 언어팩 추가

Hermes Agent v0.22.1

지정 후보의 ID와 content_hash가 일치하며 draft=false, prerelease=false인 공식 GitHub 릴리스다. 원문 제목과 공개 시각을 보존했고 공식 릴리스 본문을 직접 조회했으며 최종 URL의 HTTP 200을 확인했다. 운영 동작 수정이 있어 게시 및 공식 대표 후보로 적합하다. 보안 긴급도·breaking 여부·다른 신호와의 연관성은 확정하지 않으며 관련 항목은 escalation 후보로만 취급한다.

핵심 요약

Nous Research가 Hermes Agent v0.22.1 패치 릴리스를 공개했다. 공식 릴리스 노트에는 대화 압축 후 스킬 재로딩 표식 유지, MCP·플러그인의 서버별 호출 제한시간 보존, 프로필의 모델·사용자 지정 엔드포인트 상속 수정이 포함됐다. 모델 선택 목록 개선과 한국어 Desktop 언어팩의 플러그인 카탈로그 추가도 명시됐다.

왜 중요

장시간 에이전트 세션에서 압축 이후 스킬 지침을 다시 불러오는 동작과 외부 도구 호출 제한시간의 일관성은 운영 안정성에 직접 영향을 준다. 단순 홍보가 아니라 공식 릴리스로 확인된 동작 수정이므로 의미 있는 운영 변경이다.

우리 영향

압축을 반복하는 세션, MCP·플러그인 연동, 여러 프로필과 사용자 지정 모델 엔드포인트를 사용하는 운영자는 관련 수정의 적용 여부를 점검할 가치가 있다. 릴리스 노트에는 게이트웨이 공유 세션·인증·권한 처리 변경도 포함돼 있으므로 기존 연동의 회귀 여부는 별도 검증이 필요하다. 실제 설치 버전과 현장 개선 효과는 이번 출처 검토로 확인하지 않았다.

지금 할 일

뉴스로 게시하되 Hermes 자체의 자동 업데이트나 서비스 변경은 실행하지 않는다. 도입 검토 시 스테이징에서 압축 후 스킬 재로딩, MCP 제한시간, 프로필 엔드포인트 상속, 게이트웨이 연결을 확인한다. 인증·권한 및 의존성 감사 관련 변경과 잠재적 호환성 영향은 escalation 후보로만 표시하고 담당자 검토 후 적용 여부를 결정한다.
