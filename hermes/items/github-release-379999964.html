Hermes Agent v0.21.0 (v2026.8.31)

에스컬레이션 후보: 보안·권한·게이트웨이·cron 호환성 검증 후 단계적 적용 · 공식 릴리스·Docs·저장소 태그 교차확인 · 명시적 breaking 근거 없음 · 별도 교차신호 없음

핵심 요약

v0.20.1~v0.20.6 패치 구간을 통합 문서화한 공식 마이너 릴리스다. Desktop 기본 내장 Bot Mode와 그룹 대화, 에이전트 간 메시지를 보내는 hermes peer, 기억·연속성·노트패드·변경 감지형 monitor mode를 갖춘 cron, 실행 중 하위 에이전트 조정, MCP 통합 관리 화면, 앱 내 브라우저 제어, 신규 모델 공급자와 보안 강화를 포함한다.

왜 중요

프로필·게이트웨이·예약 작업·MCP·Desktop·CLI 등 실제 Hermes Agent 운영 면이 한 번에 크게 바뀌는 정식 릴리스다. 특히 에이전트 간 통신과 cron의 영속 문맥은 자동화 구조를 확장하지만, 권한 경계와 중복 전송·문맥 오염·비용 관리 방식도 함께 재검토해야 한다.

우리 영향

Bot Mode와 hermes peer로 다중 에이전트 협업 경로가 늘고, cron 연속성과 monitor mode로 반복 작업의 중복 및 불필요한 모델 호출을 줄일 수 있다. 반면 보호 지침 파일 쓰기 승인, 비밀정보 가림, 플러그인 보안 검사, MCP 인증·도구 권한, 게이트웨이 일시정지형 업데이트, Desktop 업데이트 방식이 달라져 기존 설정과 자동화의 호환성 회귀시험이 필요하다.

지금 할 일

운영 환경을 자동 업데이트하지 않는다. 별도 시험 환경에서 프로필·Bot Chat·hermes peer, 게이트웨이 전달, cron 기억·연속성·변경 감지, MCP 인증과 최소 권한, 보호 파일 승인·비밀정보 가림, CLI·Desktop 업데이트를 순서대로 검증한 뒤 백업과 롤백 절차를 확보해 단계적으로 적용한다.
