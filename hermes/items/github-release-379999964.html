Hermes Agent v0.21.0 (v2026.8.31)

공식 대형 릴리스 확인 · 보안 강화 포함으로 escalation 후보 · 명시적 breaking change 미확인 · 별도 교차신호 없음 · 자동 업데이트 금지

핵심 요약

v0.20.1~v0.20.6 패치 내용을 통합한 공식 대형 릴리스다. 데스크톱 기본 Bot Mode와 그룹 대화, 에이전트 간 hermes peer 메시지, 영구 메모리·연속성을 갖춘 cron, 실행 중 서브에이전트 제어, 통합 MCP 관리 화면, 에이전트가 직접 조작하는 데스크톱 브라우저, 신규 모델 공급자와 보안 강화가 핵심이다.

왜 중요

프로필·Gateway 간 협업, 예약 작업의 기억과 중복 방지, 서브에이전트 통제, MCP 비용·상태 관리, 브라우저 자동화처럼 실제 Hermes Agent 운영 경로가 한 번에 크게 달라진다. 또한 보호된 지시 파일 쓰기 승인과 비밀정보 가림 강화는 운영 보안 기준에 직접 영향을 준다.

우리 영향

Bot Mode와 hermes peer를 통한 다중 에이전트 협업, cron 결과의 지속성, 장시간 위임 작업의 중간 제어, MCP 상태·사용량 가시성, 데스크톱 브라우저 자동화가 개선될 수 있다. 반면 기본 활성화된 데스크톱 기능과 대규모 누적 변경, 승인·가림 정책 강화로 기존 프로필·Gateway·cron·MCP·업데이트 절차의 회귀시험이 필요하다.

지금 할 일

운영 환경에 자동 업데이트하지 않는다. 별도 시험 환경에서 백업과 복구 절차를 준비한 뒤 Bot Mode·그룹 대화·hermes peer, cron 메모리·연속성, 서브에이전트 제어, MCP 인증·비용 표시, 브라우저 조작, 보호 파일 승인과 비밀정보 가림, 데스크톱 업데이트를 회귀검증하고 단계 적용 여부를 결정한다.
