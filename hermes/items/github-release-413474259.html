Hermes Agent v0.22.2: v0.22.1 오배포 정정·게이트웨이 재부팅 복구

Hermes Agent v0.22.2

게시 적합: 공식 안정화 릴리스이며 Hermes Agent 운영에 실질적인 변경이 있어 대표 기사로 선정할 수 있다. 알려진 세션 삭제 제한은 운영 검토용 escalation 후보로만 표시하고, 이를 보안 취약점이나 공식 breaking change로 확정하지 않는다.

핵심 요약

NousResearch가 Hermes Agent v0.22.2를 공식 공개했다. 잘못된 커밋으로 빌드돼 미출시 게이트웨이 코드와 Microsoft Store 앱의 연결 정체 문제가 포함됐던 v0.22.1을 정정하는 릴리스다. 재부팅 후 재사용된 PID 때문에 게이트웨이가 시작하지 못하는 문제를 수정하고, 노트북 절전·로컬 서버 복구·긴 프롬프트 처리 중 로컬 모델 요청의 안정성을 개선했다. 단, v0.22.1 게이트웨이에서 실행한 세션을 v0.22.2에서 삭제할 수 없는 알려진 문제가 남아 있다.

왜 중요

단순 공지 변경이 아니라 실제 배포 내용의 정정과 운영 장애 수정이다. 공식 릴리스 원문과 후보의 버전·제목·핵심 변경을 대조했고, 리디렉션 후 최종 공식 릴리스 URL의 HTTP 200을 확인했다.

우리 영향

systemd·launchd·Docker로 감독되는 게이트웨이는 재부팅 후 기동 안정성 개선의 대상이다. 노트북에서 긴 대화를 처리하는 로컬 모델 사용자와 Windows 통합 메모리 환경도 관련된다. v0.22.1 사용자는 기존 세션 삭제 제한을 별도로 고려해야 하며, 이 공지는 개별 설치 환경의 업데이트 완료를 뜻하지 않는다.

지금 할 일

현재 버전과 v0.22.1 세션 사용 여부를 확인하고 백업 후 별도 승인된 절차로 업데이트를 검토한다. 업데이트를 수행한다면 재부팅 후 게이트웨이 기동과 로컬 모델의 긴 요청을 점검한다. 기존 세션 삭제 제한은 escalation 후보로 표시하며 자동 업데이트나 컨테이너 조작은 수행하지 않는다.
