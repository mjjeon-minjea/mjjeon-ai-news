Hermes 공식 문서, MCP로 Hermes Cloud를 관리하는 운영 가이드 추가

Hermes Agent docs add a guide for managing Hermes Cloud with MCP

공식 Hermes Cloud MCP 운영 가이드 추가 확인 · 자동 업데이트 불필요

핵심 요약

Hermes Agent 공식 문서 색인에 로컬 Hermes를 Nous Portal MCP 서버와 연결해 Hermes Cloud 인스턴스를 대화형으로 관리하는 가이드가 추가됐습니다. OAuth PKCE로 조직 권한을 확인하며 목록·상태·비용 조회와 시작·중지·재시작·생성·삭제·환경 및 이미지 변경을 지원한다고 공식 문서와 저장소에서 교차확인했습니다.

왜 중요

터미널을 벗어나지 않고 여러 Hermes Cloud 인스턴스를 조회하고 운영할 수 있어 관리 흐름이 단순해집니다. 동시에 변경 도구까지 노출되므로 조회 전용 연결과 변경 가능한 연결의 권한 범위를 구분하는 것이 중요합니다.

우리 영향

공식 운영 문서와 가이드가 추가된 변경이며 특정 설치·릴리스 버전의 배포를 뜻하지 않습니다. 기존 Hermes 설치본을 이 문서 신호만으로 자동 업데이트할 근거는 없고, Hermes Cloud와 Nous Portal 접근 권한이 있는 운영자에게 직접 관련됩니다.

지금 할 일

필요한 경우 먼저 agents 조회 도구만 허용한 읽기 전용 구성으로 연결과 조직 범위를 검증합니다. 시작·중지·삭제·환경 또는 이미지 변경 같은 작업은 결과와 영향 범위를 확인한 뒤 별도 승인 하에 실행하며, 설치 버전은 공식 Releases에서 따로 확인합니다.
