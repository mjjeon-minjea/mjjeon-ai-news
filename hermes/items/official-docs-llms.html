Hermes 공식 문서 색인 갱신: 게이트웨이 세션·업데이트 운영 문서 확인

Hermes Agent

공식 Docs 운영 참고 업데이트로 게시한다. 문서 색인의 운영 관련 내용을 직접 확인했으나 개별 기능의 신규 도입 시점과 릴리스 버전은 주장하지 않는다. 공식 문서와 공식 저장소의 최종 URL이 각각 HTTP 200임을 확인했다.

핵심 요약

Hermes Agent 공식 llms.txt에서 게이트웨이 로컬 세션, 명령 동작 일치, 세션 수명주기, 소스 업데이트 완료 책임, 안정 릴리스 승인·승격, 패키지 관리 문서 항목을 확인했다. 공식 저장소와 문서의 연결 관계도 확인했다. 이번 게시물은 공식 문서 색인 갱신에 대한 운영 참고 정보이며, 각 항목이 이번에 처음 도입됐다는 뜻이나 신규 릴리스 발표가 아니다. 게시 시각은 수집된 문서 Last-Modified 기준이다.

왜 중요

여러 프로필과 게이트웨이를 운영할 때 세션 소유권·명령 처리·업데이트 완료 기준을 확인할 공식 문서 진입점을 제공한다. 문서 변경 신호와 실제 설치 버전·안정 릴리스 확정은 구분해야 한다.

우리 영향

운영 문서 확인 경로가 갱신됐다. 개별 문서의 이전 내용과의 차이, 실행 환경에 반영된 기능, 설치 버전은 이번 검토로 확정하지 않는다. 보안 취약점이나 breaking change 발생도 확인되지 않았으며 자동 업데이트 근거로 사용하지 않는다.

지금 할 일

게이트웨이 세션 또는 업데이트 절차를 변경하기 전에 해당 공식 문서와 공식 Releases를 별도로 대조한다. 이번에는 뉴스 게시만 수행하고 설치·설정·서비스를 변경하지 않는다. 보안·breaking·교차신호가 확인될 경우에만 escalation 후보로 분류한다.
