공식 문서·Releases·저장소 교차확인 완료 · 운영 변경 유의미 · custom branch 업데이트 동작은 에스컬레이션 후보 · 자동 업데이트 금지

핵심 요약

Hermes Agent 공식 문서와 저장소에 최근 대화의 작업물을 별도 백그라운드 서브에이전트가 검토하는 `/review`가 추가됐고, 모든 서브에이전트가 작업공간의 프로젝트 규칙 파일을 시스템 문맥으로 받도록 보강됐습니다. Desktop의 기본 스케줄러는 잠든 보조 프로필을 포함해 모든 로컬 프로필의 예약 작업을 계속 실행하며, 소스 checkout 업데이트는 clean parked branch를 기본적으로 업데이트 대상 브랜치로 전환하고 custom branch 운영자는 `updates.parked_branch_strategy: update_in_place`를 명시할 수 있습니다.

왜 중요

독립 검토가 CLI·TUI·Desktop·메시징 표면에서 같은 흐름으로 동작하고, 위임 작업이 저장소별 운영 규칙을 빠뜨릴 가능성이 줄었습니다. 여러 프로필을 Desktop으로 운영할 때 보조 프로필을 열어 두지 않아도 예약 작업이 멈추지 않으며, 장기 custom branch를 쓰는 운영자는 업데이트 시 브랜치 처리 방식을 의도에 맞게 고정할 수 있습니다.

우리 영향

다중 에이전트 검토 품질과 다중 프로필 예약 작업 신뢰성에는 긍정적입니다. 다만 clean parked branch의 기본 업데이트 동작은 장기 custom branch 운영 방식에 영향을 줄 수 있어 breaking 가능성의 에스컬레이션 후보로만 표시합니다. 공식 Releases의 최신 태그는 여전히 v0.20.5이므로 이 문서 변경이 현재 설치본에 포함됐다고 단정하지 않습니다.

지금 할 일

자동 업데이트하지 않습니다. 적용이 필요하면 공식 Releases와 현재 설치 유형·버전을 먼저 확인하고, 읽기 전용 `hermes update --plan`으로 전체 프로필과 재시작 범위를 점검합니다. custom branch 설치는 업데이트 전에 `updates.parked_branch_strategy` 선택과 복구 수단을 검토하고, `/review` 사용 시 별도 모델을 지정하면 추가 추론 비용이 생길 수 있음을 확인합니다.
