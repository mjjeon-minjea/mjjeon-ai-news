Hermes Tool Search, Nous 앱 커넥터를 원격 도구로 통합

Hermes Agent Documentation Index (2026-09-09)

공식 Docs·repository 교차확인 완료 · 커넥터 검색·호출 운영 변경 유의미 · 최신 공식 릴리스 v0.21.1 유지 · 자동 업데이트 금지 · 보안·비용 교차신호 에스컬레이션 후보 · 명시적 breaking 근거 없음

핵심 요약

Hermes Agent 공식 문서에서 Nous Portal 로그인 사용자의 Gmail·Linear·Notion 등 앱 커넥터를 `tool_search`로 검색하고 `tool_describe`로 스키마를 불러온 뒤 `tool_call`로 실행하는 흐름을 확인했습니다. 커넥터 결과는 로컬 도구와 함께 한 번에 순위화되며, 원격 게이트웨이가 느리거나 응답하지 않으면 로컬 결과만 반환합니다. 공식 저장소 구현과 문서를 교차확인했고 최신 공식 릴리스는 v0.21.1로 유지됩니다.

왜 중요

기존 MCP·플러그인뿐 아니라 계정 기반 업무 앱 도구도 필요한 순간에만 검색·호출할 수 있어 도구 스키마가 문맥을 과도하게 차지하는 문제를 줄이면서 Gmail·캘린더·업무 서비스 연결을 같은 인터페이스로 운영할 수 있습니다.

우리 영향

이 기능은 Nous Portal 로그인, 관리형 도구 사용 권한, `tools.connectors.enabled` 조건을 모두 충족할 때만 노출됩니다. 연결되지 않은 계정은 `manage_connections`로 인증을 시작하며, 배치의 각 커넥터 호출은 입력 순서대로 별도 원격 요청이 되고 `/stop` 이후 시작되지 않은 호출은 전송되지 않습니다. 외부 앱 권한·데이터 전송·구독 사용량이 수반될 수 있어 보안·비용 조건은 에스컬레이션 후보입니다.

지금 할 일

이 문서 신호만으로 설치 버전을 확정하거나 자동 업데이트하지 않습니다. 실제 사용 전 공식 Releases와 현재 설치본의 지원 여부를 확인하고, 필요한 커넥터만 최소 권한으로 연결해 시험 환경에서 검색 정확도·승인·중단·오류 처리를 검증합니다. Portal 구독과 원격 호출 비용·데이터 범위도 먼저 확인합니다.
