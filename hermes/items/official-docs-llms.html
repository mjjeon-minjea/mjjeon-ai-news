Hermes 공식 문서 색인 갱신: 게이트웨이·복구·업데이트 운영 참고

Hermes Agent

공식 문서 색인 갱신 확인 · 운영 참고용 게시 · 개별 기능의 신규 도입 및 릴리스 버전 확정 아님

핵심 요약

Hermes Agent 공식 llms.txt 문서 색인 갱신 후보를 직접 검토했습니다. 현재 색인에는 다중 프로필 게이트웨이, 게이트웨이 세션 생명주기, 세션 저장소·state.db 복구, 소스 업데이트 완료 처리, 안정 릴리스 승인·승격 안내가 포함되어 있습니다. 공식 문서와 NousResearch 저장소의 최종 URL은 모두 HTTP 200으로 확인했습니다. 개별 항목의 신규 추가 시점이나 기능 변경은 이번 색인만으로 확정하지 않습니다.

왜 중요

게이트웨이 운영, 세션 복구, 업데이트 절차를 확인할 때 공식 안내로 연결되는 색인입니다. 문서 갱신과 소프트웨어 릴리스를 구분해 운영 판단의 근거로 활용할 수 있습니다.

우리 영향

다중 게이트웨이·세션 복구·업데이트 운영 문서의 참조 경로를 확인했습니다. 이번 후보는 문서 색인 변경이며 설치된 버전이나 실행 환경의 변경을 의미하지 않습니다. 게시 시각은 후보의 공식 문서 Last-Modified 기준이며 릴리스 시각이 아닙니다.

지금 할 일

운영 참고용 공식 문서 갱신으로 게시합니다. 적용이 필요한 경우 해당 공식 문서와 Releases·repository를 별도로 대조하고 승인 후 수동 검토합니다. 자동 설치·자동 업데이트는 수행하지 않습니다. 보안·breaking·교차신호 조건은 확인되는 경우 escalation 후보로만 표시합니다.
