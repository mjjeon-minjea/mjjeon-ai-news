Hermes 공식 문서 색인 갱신: LLM 없는 예약 작업·스크립트 결과 전달 참고

Hermes Agent

공식 Docs의 운영 참고 정보 보완으로 게시합니다. 공식 llms.txt와 NousResearch 공식 repository를 직접 조회했으며, 리디렉션을 따르는 GET으로 최종 URL https://hermes-agent.nousresearch.com/docs/llms.txt 및 https://github.com/NousResearch/hermes-agent 모두 HTTP 200을 확인했습니다. repository는 내장 cron 스케줄러와 플랫폼 전달을 안내하며, 스크립트 전용 방식의 설명은 이번 공식 색인에서 확인한 범위입니다. 제공된 기존 게시 요약 대비 LLM 없는 예약 작업과 스크립트 결과 전달의 구체적 참고 경로를 보완하므로 meaningful change로 판단합니다. 이전 원문과의 행 단위 차이는 제공되지 않았고 개별 연결 문서 본문과 실제 실행 동작은 이번 검토에서 확인하지 않았으므로 문서 신설 시점·기능 도입 시점·세부 적용 절차는 확정하지 않습니다. 보안·breaking change·교차신호 조건은 escalation 검토 후보로만 취급하며 이번 색인만으로 발생을 확정하지 않습니다.

핵심 요약

Hermes Agent 공식 llms.txt를 직접 확인했습니다. 현재 색인은 Script-Only Cron Jobs (No LLM)를 모델 호출 없이 일정에 따라 스크립트를 실행하고 표준출력을 메시징 플랫폼으로 전달하는 가이드로 소개합니다. Pipe Script Output to Messaging Platforms는 셸 스크립트·cron·CI·모니터링 결과를 hermes send로 Telegram·Discord 등으로 보내는 참고 경로입니다. 기존 게시의 관리자 고정 설정·Docker 외부 통신 격리 안내에 경량 자동화와 결과 전달의 운영 참고 정보를 보완합니다. 문서 색인 확인이며 신규 기능 출시나 설치 버전 변경을 뜻하지 않습니다. 표시된 원문 시각은 후보에 기록된 문서 Last-Modified 기준으로, 기능 출시일이 아닙니다.

왜 중요

단순 상태 점검과 정형 알림을 매번 LLM에 맡겨야 하는지 검토하고, 스크립트 실행과 메시징 전달을 분리해 운영할 때 참고할 공식 문서 경로입니다. 모델 호출을 생략하는 방식과 작업 전체의 비용이 없다는 주장은 다르며, 스크립트가 사용하는 외부 API·인프라·메시징 서비스 비용은 별도로 확인해야 합니다.

우리 영향

기존 게시 요약에 없던 스크립트 전용 예약 작업과 결과 전달의 구체적 참고 경로를 보완하는 문서 정보 갱신입니다. 이번 작업은 공식 출처 확인과 뉴스 게시에 한정하며 실행 중인 Hermes의 버전·설정·권한·네트워크·컨테이너·예약 작업은 변경하지 않습니다. 실제 적용 가능 여부와 비용 절감 효과는 검증하지 않았습니다.

지금 할 일

경량 점검·알림 자동화를 검토할 때 공식 색인의 Script-Only Cron Jobs (No LLM)와 Pipe Script Output to Messaging Platforms 문서를 확인합니다. 실제 도입은 개별 문서 본문·공식 Releases·repository 및 사용 중인 설치 방식과 비용 조건을 별도로 대조하고 승인받습니다. 문서 갱신만으로 설치·릴리스 버전을 확정하거나 자동 업데이트·예약 작업 변경을 하지 않습니다.
