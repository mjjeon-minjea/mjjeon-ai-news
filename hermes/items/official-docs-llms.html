핵심 요약

Hermes Agent 공식 문서 index가 native Windows·WSL, 다중 profile gateway, managed scope와 여러 secret source, provider routing·fallback·credential pool, MCP·plugin 확장 등 설치·운영·보안 경로를 폭넓게 명시했습니다. 공식 원문 URL과 39,742-byte 판본의 SHA-256을 확인했습니다.

왜 중요

이번 판본은 단순 사용법 한 항목이 아니라 설치 플랫폼, 다중 인스턴스 운영, 비밀값·egress, 공급자 장애대응, 도구·플러그인 확장까지 운영 의사결정에 직접 쓰이는 공식 문서 진입점을 함께 확장했습니다.

우리 영향

플랫폼·게이트웨이·비밀값·모델 공급자·외부 도구 연결 경로가 세분화돼 운영자가 배포 형태별 설정과 보안 경계를 더 정확히 확인할 수 있습니다. 다만 문서 index의 등재만으로 현재 설치본의 기능 포함이나 호환성을 확정할 수 없고, credential·egress·plugin·다중 gateway 변경은 운영 검증이 필요합니다.

지금 할 일

자동 업데이트하지 않습니다. 실제 적용 전 현재 설치 유형과 버전, 백업·롤백 경로를 확인하고 별도 시험 환경에서 Windows·WSL·Docker, 다중 profile gateway, managed scope·secret source, provider routing·credential pool, MCP·plugin 동작을 회귀검증합니다.
