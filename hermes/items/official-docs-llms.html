Hermes 공식 문서 색인 갱신: 관리자 고정 설정·Docker 외부 통신 격리 참고

Hermes Agent

공식 Docs의 운영 참고 정보 보완으로 게시합니다. 공식 llms.txt와 NousResearch 공식 repository를 직접 조회했으며 리디렉션을 따르는 GET으로 최종 URL https://hermes-agent.nousresearch.com/docs/llms.txt 및 https://github.com/NousResearch/hermes-agent 모두 HTTP 200을 확인했습니다. 기존 게시 요약 대비 관리자 고정 정책과 Docker 외부 통신 격리의 구체적인 참고 경로를 보완하므로 meaningful change로 판단합니다. 이전 원문과의 행 단위 차이는 제공되지 않았고 개별 연결 문서 본문은 이번 검토에서 조회하지 않았으므로 문서 신설 시점·기능 도입 시점·세부 적용 절차는 확정하지 않습니다. 보안 관련 경로는 escalation 검토 후보로만 표시하며 취약점·보안 패치·breaking change나 교차신호 발생을 이번 색인만으로 확정하지 않습니다.

핵심 요약

Hermes Agent 공식 llms.txt를 직접 확인했습니다. 현재 색인은 관리자가 고정하고 사용자가 변경할 수 없는 설정·비밀정보 범위를 설명하는 Managed Scope, 에이전트 샌드박스가 허용된 호스트에만 접근하도록 Docker 네트워크를 분리하는 Network Egress Isolation, 자격증명 주입 프록시인 iron-proxy의 운영·내부 구조 문서로 연결됩니다. 기존 게시의 원격 설정·세션 복구·Kanban 안내에 관리자 통제와 외부 통신 제한의 공식 참고 경로를 보완합니다. 문서 색인 확인이며 이번 신규 기능 도입이나 새 버전 출시를 뜻하지 않습니다. 표시된 원문 발행 시각은 후보에 기록된 문서 Last-Modified 기준으로, 기능 출시일이 아닙니다.

왜 중요

다중 프로필·Docker 환경에서 사용자 설정과 관리자 고정 정책을 구분하고, 샌드박스의 외부 접근 범위와 자격증명 전달 방식을 검토할 때 참고할 공식 문서 경로를 제공합니다. 문서에 정책이 설명되어 있다는 사실과 실제 운영 환경에서 해당 정책이 적용되어 있다는 사실을 구분해야 합니다.

우리 영향

기존 게시 요약에 없던 관리자 고정 설정·비밀정보 관리와 Docker 외부 통신 격리의 참고 경로를 보완하는 문서 정보 갱신입니다. 이번 작업은 공식 출처 확인과 뉴스 게시에 한정하며 실행 중인 Hermes의 버전·설정·권한·네트워크·컨테이너나 예약 작업은 변경하지 않습니다.

지금 할 일

관리자 정책이나 Docker 외부 통신 제한을 검토할 때 공식 색인의 Managed Scope·Network Egress Isolation·iron-proxy 문서를 확인합니다. 실제 적용은 공식 Releases·repository와 사용 중인 설치 방식 및 네트워크 구성을 별도로 대조하고 승인받습니다. 문서 갱신만으로 설치·릴리스 버전을 확정하거나 자동 업데이트하지 않습니다.
