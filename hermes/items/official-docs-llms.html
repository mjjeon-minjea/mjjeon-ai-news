Hermes Agent

공식 문서 색인의 운영 관련 항목 변화를 정보성 업데이트로 게시합니다. 보안·파괴적 변경이나 릴리스 확정 신호로 해석하지 않으며 그런 조건은 별도 escalation 후보로만 다룹니다. published_at은 개별 안내 페이지 게시일이 아니라 후보에 기록된 llms.txt HTTP Last-Modified 시각입니다.

핵심 요약

Hermes Agent 공식 llms.txt 문서 색인에서 Nix 설치, Android/Termux 설치, 다중 게이트웨이, 관리형 설정, Docker 네트워크 격리 등 운영 관련 안내 페이지로 이어지는 링크를 확인했습니다. 이 자료는 문서 목차이며 새 릴리스 또는 설치 버전 공지가 아닙니다.

왜 중요

운영자는 공식 문서의 설치 방식·격리·설정 관리 경로를 한곳에서 찾아 환경별 변경 사항을 검토할 수 있습니다. 색인 갱신만으로 개별 기능의 출시 시점이나 버전을 확정할 수는 없습니다.

우리 영향

공식 문서의 운영 안내 접근성이 확대됐습니다. 기존 설치 환경에 즉각적인 변경을 요구하거나 자동 업데이트를 정당화하는 근거는 아닙니다.

지금 할 일

필요한 항목은 해당 공식 문서 본문과 저장소를 별도로 대조한 뒤 테스트 환경에서 검토합니다. 이 색인을 근거로 운영 중인 Hermes를 자동 업데이트하지 않습니다.
