Hermes Agent

공식 docs 후보로 검토했습니다. 공식 문서 색인과 NousResearch 저장소를 직접 읽었고 두 URL 모두 리다이렉트 후 동일한 공식 주소에서 HTTP 200을 확인했습니다. 운영 참고문서 안내를 담은 색인 갱신으로 게시하되 특정 문서나 기능이 이번에 처음 추가됐다고 단정하지 않습니다. published_at은 후보의 HTTP Last-Modified 시각이며 개별 문서의 최초 발행일은 아닙니다. 보안·breaking·교차신호에 대한 확정 판단은 하지 않습니다.

핵심 요약

Hermes Agent 공식 llms.txt 갱신 후보를 직접 확인했습니다. 현재 색인은 패키지 관리, 안정 릴리스 승인·승격, 소스 업데이트 완료 처리, 공유 번들 빌드 등 운영 참고문서를 안내합니다. 공식 GitHub 저장소도 같은 공식 문서 사이트를 안내하며, 이번 항목은 릴리스 발표가 아닌 문서 색인 업데이트입니다.

왜 중요

배포 방식과 업데이트 절차를 검토할 때 공식 운영문서를 찾는 진입점입니다. 문서에 항목이 있다는 사실과 실행 환경에 해당 기능이나 버전이 설치됐다는 사실을 구분해야 합니다.

우리 영향

운영자는 공식 색인에서 패키지 관리와 릴리스·업데이트 관련 문서를 찾아 수동 검토할 수 있습니다. 이번 확인만으로 개별 기능의 신규 도입, 보안 수정, 호환성 변경 또는 설치 버전을 확정하지 않습니다.

지금 할 일

공식 문서 갱신 소식으로 게시하되 자동 설치나 버전 업데이트는 실행하지 않습니다. 실제 환경 변경 전 해당 운영문서와 릴리스 정보를 별도 확인하며, 보안·breaking·교차신호가 확인되면 escalation 후보로만 분류합니다.
