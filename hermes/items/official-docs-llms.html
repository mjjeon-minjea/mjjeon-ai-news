Hermes 공식 문서 갱신: PM 설치 관리와 프로필별 게이트웨이 운영 가이드

Hermes Agent

지정 ID와 content_hash가 일치하는 공식 문서 후보를 검토했습니다. 공식 문서와 공식 저장소를 직접 조회하고 각각 리다이렉트 이후 최종 공식 URL 및 HTTP 200을 확인했습니다. 설치 관리와 다중 프로필 운영에 직접 참고할 수 있는 공식 문서 갱신으로 채택하되, 이번 색인에서 각 항목이 새로 추가되었다거나 새 버전이 출시되었다고 판단하지 않습니다. 보안 수정과 breaking change도 확정하지 않습니다. published_at은 별도 발행일이 아닌 수집 당시 공식 Last-Modified 기준입니다.

핵심 요약

Hermes Agent 공식 llms.txt 색인에서 PM의 도구 버전 고정·Python 환경·설치 소유권 가이드, 여러 프로필의 게이트웨이 운영, 소스 설치 전환 문서를 확인했습니다. 공식 저장소도 소스 설치의 Python·Node.js 등 의존성 관리를 PM에 위임한다고 설명하며, 패키지형 설치와 소스형 설치의 업데이트 주체를 구분합니다. 이번 항목은 공식 문서의 운영 참고 사항이며 새 릴리스 발표가 아닙니다.

왜 중요

설치 형태와 실행 프로필이 다른 Hermes 인스턴스에 같은 업데이트 절차를 일괄 적용하지 않도록, 설치 소유권과 프로필별 운영 범위를 나눠 확인할 공식 근거를 제공합니다.

우리 영향

운영자는 업데이트 전에 현재 설치 방식과 의존성 관리 주체를 확인하고, 여러 게이트웨이의 프로필 범위를 구분해 검토해야 합니다. 문서 색인만으로 특정 기능의 신규 도입 시점이나 현재 설치 환경의 지원 여부를 확정할 수는 없습니다.

지금 할 일

공식 설치·업데이트·PM 문서를 기준으로 설치 방식별 관리 주체와 프로필별 게이트웨이 범위를 먼저 확인합니다. 실제 설치나 자동 업데이트는 수행하지 않으며, 변경이 필요하면 시험 환경에서 수동 검토합니다. 보안·breaking·교차신호 조건은 escalation 후보로만 표시하고 자동 조치하지 않습니다.
