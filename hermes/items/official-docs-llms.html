Hermes 공식 llms.txt, 전체 문서 페이지를 자동 색인하도록 개선

Hermes Agent llms.txt now indexes every documentation page

공식 문서 색인 개선 확인 · 자동 업데이트 불필요

핵심 요약

Hermes Agent 공식 문서의 llms.txt 생성기가 수동 선별 목록 대신 문서 트리를 순회하도록 바뀌었습니다. 공식 저장소에 따르면 종전에는 204개 문서 중 109개가 색인에서 빠졌으며, 이제 MD·MDX 문서와 새 페이지가 자동 포함되고 잘못된 링크도 테스트로 방지됩니다.

왜 중요

Hermes 자체와 외부 AI가 기능을 확인할 때 사용하는 공식 색인의 누락이 해소되어 Bot Mode, 데스크톱, 컴퓨터 사용, 웹 검색, 다수 메시징 플랫폼 같은 기능을 없다고 잘못 판단할 가능성이 줄어듭니다.

우리 영향

실행 코드나 설치 버전의 변경은 아니지만 Hermes 기능 조사와 운영 문서 탐색의 정확도가 높아집니다. 기존 설치본의 자동 업데이트를 요구하는 변경은 아닙니다.

지금 할 일

Hermes 기능·운영 방법을 확인할 때 갱신된 공식 llms.txt와 연결된 개별 문서를 우선 참조하고, 설치 또는 릴리스 버전은 별도의 공식 Releases에서 확인합니다.
