Hermes 공식 문서 색인 갱신: 원격 설정·세션 복구·Kanban 운영 참고

Hermes Agent

공식 Docs의 운영 참고 정보 갱신으로 게시합니다. 공식 색인과 NousResearch 공식 repository를 직접 조회했고 두 URL 모두 리디렉션 뒤 최종 URL과 HTTP 200을 확인했습니다. 기존 게시 요약 대비 설정 관리·세션 복구·Kanban 전달 운영의 구체적인 참고 경로를 보완하므로 meaningful change로 판단합니다. 이전 원문과의 행 단위 차이는 제공되지 않아 개별 문서의 신설 시점이나 기능 변경 시점은 확정하지 않습니다. 보안·breaking·교차신호 조건은 확인 시 escalation 후보로만 표시하며 이번 색인만으로 해당 변경을 확정하지 않습니다.

핵심 요약

Hermes Agent 공식 llms.txt의 갱신을 확인했습니다. 현재 색인은 프로필별 원격 설정, 세션 저장소 복구, 단일 디스패처와 프로필별 전달을 설명하는 Kanban 다중 게이트웨이 운영 가이드로 연결됩니다. 기존 게시의 업데이트·다중 게이트웨이·cron 안내에 이어 설정 관리와 장애 복구의 공식 확인 경로를 보완합니다. 문서 색인 확인이며 해당 기능의 이번 신규 도입이나 새 버전 출시를 뜻하지 않습니다. 게시 시각은 후보에 기록된 문서 Last-Modified 기준으로, 기능 출시일이 아닙니다.

왜 중요

다중 프로필 환경에서 설정을 어디서 관리하는지, 세션 저장소 문제가 생겼을 때 무엇을 참고하는지, Kanban 작업 전달을 어떤 운영 문서와 대조할지 확인할 수 있습니다. 문서 안내와 실제 배포 상태를 구분해 색인 갱신만으로 운영 환경이 바뀌었다고 오인하지 않도록 합니다.

우리 영향

기존 게시 요약에 없던 원격 설정·세션 복구·Kanban 운영 참고 경로를 보완하는 문서 정보 갱신입니다. 이번 작업은 공식 출처 확인과 뉴스 게시에 한정하며 실행 중인 Hermes의 버전·설정·컨테이너나 예약 작업은 변경하지 않습니다.

지금 할 일

설정 관리·장애 복구·Kanban 운영 변경을 검토할 때 공식 색인에서 해당 가이드를 먼저 확인하고, 실제 적용은 공식 Releases·repository 및 사용 중인 설치 방식과 대조해 별도로 승인합니다. 문서 갱신만으로 설치·릴리스 버전을 확정하거나 자동 업데이트하지 않습니다.
