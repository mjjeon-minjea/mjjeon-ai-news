Hermes 공식 문서에서 패키지 관리·안정 릴리스·업데이트 완료 지침 확인

Hermes Agent

게시: 공식 문서와 공식 저장소를 직접 대조해 Hermes 운영에 관련된 안내를 확인했습니다. 두 출처의 최종 URL은 각각 공식 도메인과 NousResearch 저장소를 유지하며 HTTP 200입니다. 의미는 운영 문서 안내에 한정하고 이전 색인 대비 특정 항목의 신규 추가나 기능 출시를 단정하지 않습니다. published_at은 수집된 공식 문서 Last-Modified 기준입니다. 이번 검토 범위에서 보안·breaking 또는 별도 교차신호에 따른 escalation 근거는 확인하지 못했습니다.

핵심 요약

Hermes Agent 공식 llms.txt에서 패키지 관리, 안정 릴리스 승인·승격, 소스 업데이트 완료 책임, 세션 저장소 복구에 관한 운영 문서 항목을 확인했습니다. 공식 저장소도 패키지 관리 문서를 개발 환경 운영의 출발점으로 안내합니다. 이번 소식은 공식 문서의 운영 안내이며, 새 버전 출시나 각 기능의 신규 도입 시점을 뜻하지 않습니다.

왜 중요

설치 형태와 업데이트 경로, 안정 릴리스 판단, 저장소 복구를 구분해 확인할 공식 문서 진입점이 제공됩니다. 운영자는 문서 색인 변경을 곧바로 릴리스나 업데이트 승인으로 오인하지 않고 해당 절차를 확인할 수 있습니다.

우리 영향

Hermes 운영·개발 환경에서 설치 소유권과 패키지 관리, 업데이트 완료 확인, 세션 저장소 복구 안내를 찾아보기 쉬워집니다. 문서와 저장소 main의 변경은 실제 설치 버전 및 정식 릴리스 상태와 별도로 판단해야 합니다.

지금 할 일

운영 환경의 설치 형태에 맞는 공식 패키지 관리·업데이트 문서를 검토하고 실제 변경 적용은 별도 승인 절차로 진행합니다. 이번 문서 확인만으로 설치 버전을 확정하거나 자동 업데이트하지 않습니다. 보안·호환성 파괴 변경 또는 교차신호가 확인되는 경우에는 escalation 후보로만 표시합니다.
