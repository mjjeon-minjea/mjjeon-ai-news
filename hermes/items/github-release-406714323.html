Hermes Agent v0.21.6 공개: Docker·Cloud 안정 릴리스와 새 배포 파이프라인

Hermes Agent v0.21.6

지정 ID와 content_hash가 일치하는 공식 GitHub Releases 후보이며 원문 제목·태그·발행시각을 확인했다. 공식 릴리스 본문을 직접 조회하고 최종 URL의 HTTP 200 응답을 검증했다. 안정 태그·Docker 이미지 공개와 배포 채널별 적용 차이는 Hermes 운영에 의미 있는 변경이므로 공식 업데이트로 게시하고 대표 항목 후보로 허용한다.

핵심 요약

NousResearch가 Hermes Agent v0.21.6을 정식 패치 릴리스로 공개했다. v0.21.5 이후 병합된 약 2,100개 PR을 Docker와 Hermes Cloud용 안정 태그로 묶었으며, 새 안정 릴리스 파이프라인에서 테스트한 Docker 이미지와 릴리스 태그를 배포한다. Desktop 앱·Termux 패키지·Microsoft Store는 이번 릴리스에서 기존 빌드를 유지한다. 이 변경 구간의 상세 정리 노트는 v0.22.0에서 제공될 예정이다.

왜 중요

단순 예고가 아니라 공식 안정 태그와 Docker 이미지가 공개되어 Hermes 운영 환경의 업데이트 검토 근거가 생겼다. 배포 채널별 적용 범위가 달라 모든 클라이언트가 동시에 새 버전으로 바뀐다고 해석하면 안 된다.

우리 영향

Docker·Hermes Cloud 운영자는 stable 또는 latest 이미지의 적용 범위를 확인할 필요가 있다. Git 기반 CLI 설치는 공식 노트의 hermes update 경로를 참고할 수 있다. 릴리스 노트는 cron 저장소 쓰기 불가 경고, 요약형 hermes status, 프로필별 플러그인 호스트 등 운영 관련 변경을 함께 언급하지만, 세부 영향은 상세 노트와 실제 환경 검증이 필요하다.

지금 할 일

현재 설치 버전과 배포 채널을 확인하고 변경 영향·백업·롤백 절차를 검토한 뒤 승인된 테스트 환경에서 업데이트를 검증한다. 이번 뉴스 게시로 설치 버전을 변경하거나 자동 업데이트하지 않는다. 자격 증명 업로드 승인 및 터미널 명령의 비가시 Unicode 관련 변경은 보안 검토용 escalation 후보로만 표시하며, 긴급 취약점이나 breaking change로 확정하지 않는다.
