Hermes Agent v0.21.6: Docker·Cloud 안정 릴리스와 채널별 적용 범위

Hermes Agent v0.21.6

지정 stable_id와 content_hash가 정확히 일치하는 후보 raw를 검토했다. 공식 GitHub 릴리스 원문을 직접 조회했으며 최종 URL이 지정 v0.21.6 릴리스 URL과 일치하고 HTTP 200임을 확인했다. 원문 제목과 발행시각을 보존한다. 안정 릴리스 파이프라인, 채널별 배포 범위 및 공식 본문의 운영 변경 안내는 의미 있는 변경으로 판단해 official/release로 게시하고 대표 항목 후보로 허용한다. 보안 관련 승인 변경은 escalation 후보로만 취급하며 설치 버전 확정·자동 업데이트·breaking change 확정은 하지 않는다.

핵심 요약

NousResearch가 10월 8일 Hermes Agent v0.21.6 패치 릴리스를 공개했다. v0.21.5 이후 약 2,100개 PR을 Docker와 Hermes Cloud용 안정 태그로 묶었으며, 새 안정 릴리스 파이프라인에서 테스트된 Docker 이미지와 배포 확인 태그를 함께 공개한 첫 릴리스라고 설명한다. 공식 본문은 스트리밍 음성 전사, 프로필별 플러그인 호스트, 로컬 모델, cron 저장소 쓰기 불가 경고, 자격 증명 업로드·보이지 않는 유니코드 명령 승인 등도 이 변경 구간에 포함됐다고 안내한다. 전체 정리된 릴리스 노트는 v0.22.0에서 제공할 예정이다. 이번 공개 범위는 Git 태그·GitHub 릴리스·Docker 이미지이며 Desktop·Termux·Microsoft Store는 현재 빌드를 유지한다.

왜 중요

안정 태그와 테스트된 Docker 이미지의 배포 절차, 채널별 적용 범위를 공식적으로 구분한 운영 변경이다. 기능 목록은 공식 릴리스 본문에 근거하지만 상세한 통합 노트가 아직 예정되어 있어, 모든 배포 채널에 같은 기능이 즉시 적용됐다고 해석하면 안 된다.

우리 영향

Docker·Hermes Cloud에는 새 안정 릴리스가 안내됐고 Git 기반 CLI에는 별도 업데이트 절차가 제시됐다. Desktop·Termux·Microsoft Store는 이번 릴리스로 빌드가 바뀌지 않는다. 플러그인 실행 격리, 음성 모델 분리, cron 쓰기 경고와 승인 처리 변경은 운영 점검 대상이며, 이 기사는 현재 설치 버전이나 실제 동작 검증을 뜻하지 않는다.

지금 할 일

사용 중인 배포 채널을 먼저 확인하고 별도 승인과 검증을 거쳐 업데이트를 검토한다. 공식 안내는 Docker·Cloud의 stable 또는 latest 이미지와 Git 설치의 hermes update이며, 이번 게시 작업에서는 설치·자동 업데이트를 수행하지 않는다. 플러그인 호스트와 cron 저장 권한, 음성 설정, 자격 증명 업로드·유니코드 명령 승인 동작은 적용 전 점검한다. 보안 관련 승인 변경은 escalation 검토 후보로만 표시하고 취약점이나 breaking change로 단정하지 않는다. 상세 변경 범위는 예정된 v0.22.0 통합 노트에서 추가 확인한다.
