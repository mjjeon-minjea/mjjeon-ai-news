Hermes Agent v0.21.6 공개: Docker·Cloud 안정 릴리스와 새 배포 파이프라인

NousResearch가 Hermes Agent v0.21.6을 정식 패치 릴리스로 공개했다. v0.21.5 이후 병합된 약 2,100개 PR을 Docker와 Hermes Cloud용 안정 태그로 묶었으며, 새 안정 릴리스 파이프라인에서 테스트한 Docker 이미지와 릴리스 태그를 배포한다. Desktop 앱·Termux 패키지·Microsoft Store는 이번 릴리스에서 기존 빌드를 유지한다. 이 변경 구간의 상세 정리 노트는 v0.22.0에서 제공될 예정이다.

지정 ID와 content_hash가 일치하는 공식 GitHub Releases 후보이며 원문 제목·태그·발행시각을 확인했다. 공식 릴리스 본문을 직접 조회하고 최종 URL의 HTTP 200 응답을 검증했다. 안정 태그·Docker 이미지 공개와 배포 채널별 적용 차이는 Hermes 운영에 의미 있는 변경이므로 공식 업데이트로 게시하고 대표 항목 후보로 허용한다.

Hermes 공식 문서에서 패키지 관리·안정 릴리스·업데이트 완료 지침 확인

Hermes Agent 공식 llms.txt에서 패키지 관리, 안정 릴리스 승인·승격, 소스 업데이트 완료 책임, 세션 저장소 복구에 관한 운영 문서 항목을 확인했습니다. 공식 저장소도 패키지 관리 문서를 개발 환경 운영의 출발점으로 안내합니다. 이번 소식은 공식 문서의 운영 안내이며, 새 버전 출시나 각 기능의 신규 도입 시점을 뜻하지 않습니다.

게시: 공식 문서와 공식 저장소를 직접 대조해 Hermes 운영에 관련된 안내를 확인했습니다. 두 출처의 최종 URL은 각각 공식 도메인과 NousResearch 저장소를 유지하며 HTTP 200입니다. 의미는 운영 문서 안내에 한정하고 이전 색인 대비 특정 항목의 신규 추가나 기능 출시를 단정하지 않습니다. published_at은 수집된 공식 문서 Last-Modified 기준입니다. 이번 검토 범위에서 보안·breaking 또는 별도 교차신호에 따른 escalation 근거는 확인하지 못했습니다.
