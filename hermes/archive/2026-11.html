Hermes Agent v0.22.6 정식 패치: 웹앱·cron·플러그인 운영 변경 통합

Nous Research가 Hermes Agent v0.22.6 정식 패치를 공개했다. 공식 릴리스 본문은 v0.22.5 이후 약 776개 병합 PR을 CLI·설치 프로그램, Microsoft Store 앱, Docker와 Hermes Cloud용 릴리스로 묶었다고 설명한다. 게이트웨이 리스너 기반 웹앱, 스킬별 자율 쓰기 잠금, cron 취소와 작업별 누락 실행 정책, 플러그인 설치·업데이트 시 최소 Hermes 버전 검사 등을 언급하며, 전체 변경에 대한 상세 정리본은 v0.23.0에서 제공할 예정이라고 명시했다.

지정 ID와 해시가 일치하는 수집 후보는 draft=false, prerelease=false인 공식 릴리스다. 공식 태그 URL의 리디렉션 후 최종 주소와 HTTP 200을 확인했다. 수집된 공식 릴리스 본문에 Hermes Agent 운영 변경이 포함되어 meaningful change로 판단하며 공식 대표 기사로 게시한다. 보안·breaking·교차신호 조건은 확정 경보나 자동 조치가 아닌 escalation 후보로만 다룬다.

Hermes 공식 문서 색인 갱신: 업데이트·다중 게이트웨이·자동화 운영 안내

Hermes Agent 공식 llms.txt의 갱신을 확인했습니다. 현재 색인은 안정 릴리스 승인·승격, 소스 업데이트 완료 책임, 여러 게이트웨이 동시 운영, 스크립트 전용 cron 등 운영 문서로 연결됩니다. 공식 저장소 연결도 확인했으며, 문서 색인 갱신을 새 버전 출시나 해당 기능의 이번 신규 도입으로 단정하지 않습니다. 게시 시각은 후보에 기록된 문서의 Last-Modified 기준으로, 개별 기능 출시일이 아닙니다.

공식 Docs의 운영 참고 정보 갱신으로 게시합니다. 공식 문서와 저장소의 최종 URL 및 HTTP 200을 확인했습니다. 보안·breaking·교차신호 조건은 확인 시 escalation 후보로만 표시하며 이번 색인만으로 해당 변경을 확정하지 않습니다.
