Hermes 공식 문서: 다중 프로필 Gateway의 기본 다중화·정지 범위 확인

Hermes Agent 공식 llms.txt와 연결된 Running Many Gateways at Once 문서 본문을 직접 확인했습니다. 문서는 하나의 호스트 Gateway가 여러 프로필을 처리하는 다중화를 기본 방향으로 설명하며, 설정이 미지정된 경우 부팅 사전 점검에서 별도 Gateway·중복 봇 자격정보·수신 경로 등의 조건을 확인한다고 안내합니다. gateway.multiplex_profiles의 false 값은 폐기되어 true로 다시 기록된다고 명시하고, 프로필별 별도 Gateway를 위한 gateway.standalone은 임시 호환 수단으로 구분합니다. 다중화된 일반 프로필의 stop은 해당 프로필을 parked 상태로 만들어 어댑터와 이후 예약 작업 실행을 제외하지만 이미 시작된 예약 작업을 종료하지는 않습니다. 기본 프로필과 --all 명령은 호스트 전체에 영향을 주는 범위를 유지합니다. 기존 세션 DB 복구·WAL 보존 요약에 없던 다중 프로필 운영 판단 정보를 보완하는 문서 검토이며 신규 릴리스나 설치 버전 변경을 뜻하지 않습니다. 원문 시각은 후보의 llms.txt Last-Modified 기준이며 기능 출시일이 아닙니다.

공식 Docs의 실질적인 운영 참고 정보 보완으로 게시합니다. 공식 llms.txt와 NousResearch 공식 repository를 직접 조회했고 리디렉션을 따르는 GET의 최종 URL https://hermes-agent.nousresearch.com/docs/llms.txt 및 https://github.com/NousResearch/hermes-agent 에서 각각 HTTP 200을 확인했습니다. llms.txt에 연결된 Running Many Gateways at Once 본문에서 설정 미지정 시의 다중화 사전 점검, 명시적 true의 차이, false 폐기 안내, 임시 standalone 호환 수단, 프로필 parking과 이후 cron 실행 제외, 이미 실행된 cron의 비종료 및 기본 프로필·--all의 호스트 전체 범위를 확인했습니다. 제공된 기존 게시 요약은 세션 DB 복구와 WAL 보존을 중심으로 하므로 이 운영 판단 정보의 보완을 meaningful change로 판단합니다. 이전 원문과 행 단위 비교를 하지 않았으므로 해당 문서나 기능의 신설·도입 시점을 확정하지 않습니다. repository의 릴리스 링크 표시는 확인했지만 공식 Releases 본문과 실제 설치 버전은 이번 검토에서 확인하지 않았으며 신규 출시나 버전별 적용을 주장하지 않습니다. 보안·breaking·교차신호 조건은 escalation 검토 후보로만 취급하고 발생을 확정하지 않습니다. 지정 후보 snapshot과 제공된 기존 게시 항목만 비교 입력으로 사용했습니다.
