2. 기술 아키텍처 및 메커니즘 분석

DeepSeek Harness는 Cordis 프레임워크에 기반한 극도로 모듈화된 에이전트 하네스입니다. 핵심 설계 사상은 'Everything is a plugin'으로 사이드바, 도구, 샌드박스, 시스템 프롬프트, 심지어 에이전트 루프 자체까지 교체 가능합니다. Trajectory View를 통해 에이전트의 사고 과정, 실행 명령, 입력/출력 페이로드를 그래픽 패널로 실시간 검사할 수 있으며, MCP(Model Context Protocol), Agent Client Protocol, Claude.md / Agents.md 파일 표준과 완벽히 호환됩니다.

3. 핵심 기능 및 워크플로우 실증

  • 4단계 프리셋 모드: Standard(일상 업무), Code(복합 개발), Minimal(초경량 질의응답), Creator(자연어 프롬프트 기반 플러그인 즉시 생성)
  • Creator Mode 플러그인 생성: '우측 하단에 오늘 할 일 체크 패널 생성'과 같은 단일 프롬프트로 UI 컴포넌트 실시간 개발 및 즉시 마운트
  • Trajectory 디버깅: 에이전트가 잘못된 폴더를 읽거나 오류가 발생했을 때 정확한 단계로 이동하여 프롬프트 및 파일 수정 후 재실행
  • 무료 모델 백엔드 연동: OpenCode 또는 OpenRouter를 연결하여 DeepSeek V4 Flash 등 무료 모델을 하네스에 플러그인하여 완전 무료 구동
