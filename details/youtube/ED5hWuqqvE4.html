2. 기술 아키텍처 및 메커니즘 분석

DeepSeek Harness는 LLM(두뇌)을 실제 작업 수행 에이전트(신체, 도구, 메모리, 샌드박스)로 감싸는 차세대 모듈형 하네스 프레임워크입니다. 핵심 철학은 'Everything is a Plugin'으로, 모델뿐만 아니라 툴셋, 메모리 시스템, 실행 샌드박스, 생각-행동-검증(Think-Act-Check) 추론 루프 전체가 탈부착 가능한 플러그인 구조로 설계되었습니다. 터미널 단일 명령어로 로컬 브라우저 UI가 구동되며, 기존 `agents.md`, `claude.md` 지침 파일을 완벽 호환합니다.

3. 핵심 기능 및 워크플로우 실증

  • 4대 실행 모드 선택: 표준 작업 모드(Standard), 코드 직접 호출 모드(Code-calling), 단순 작업용 미니멀 모드(Minimal), 신규 생성 모드(Creation) 중 최적 프로파일 로딩
  • 투명한 궤적(Trajectory View) 검증: 에이전트가 확인한 모든 컨텍스트와 실행 단계를 변경 불가능한 로그로 기록하고 일시정지, 포크(Fork), 리플레이 지원
  • 플러그인 핫 스왑: 새로운 메모리 시스템이나 외부 API 등장 시 전체 시스템을 재구축할 필요 없이 해당 플러그인만 즉시 교체
  • Agent OS 다중 에이전트 통합: 밤새 발생한 이벤트 요약 및 차일 과제 큐를 처리하는 에이전트의 하위 엔진으로 하네스 연결
