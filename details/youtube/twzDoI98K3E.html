2. 기술 아키텍처 및 메커니즘 분석

Hermes Bot Mode는 Hermes 코어의 프로필 디렉토리 격리 구조를 시각적 로스터 패널로 추상화한 플러그인입니다. 백그라운드 데몬이나 복잡한 데이터베이스 추가 없이 각 프로필(홈 디렉토리)에 고유한 config, soul 파일, 메모리 세션, 스킬, 스케줄을 부여합니다. Soul 파일은 시스템 프롬프트의 1번 슬롯에 주입되어 에이전트의 페르소나와 기본 행동 규칙을 결정합니다. 에이전트 간 통신은 Agent Inbox와 @멘션을 통해 CLI 레벨에서 자율 위임(Handoff) 방식으로 실행됩니다.

3. 핵심 기능 및 워크플로우 실증

  • 로스터 구성 및 Soul 파일 커스텀: 연구용, 콘텐츠용, 코딩용 등 전담 에이전트를 생성하고 고유 페르소나 및 모델 배정
  • 스케줄러 기반 무인 루틴 등록: Hermes 내장 크론 탭을 통해 매일 아침 인박스 요약, 정오 경쟁사 모니터링 자동 실행
  • 에이전트 간 자율 인박스 핸드오프: 메인 대화창에서 '@researcher 최신 데이터 조회' 입력 시 서브 에이전트가 자체 메모리로 조사 후 결과 회신
