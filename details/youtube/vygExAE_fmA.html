3. The Big Idea (기술적 패러다임 변화)

'화면 점유형 로컬 에이전트'에서 '완전 격리형 클라우드 가상 VDI(Virtual Desktop for Agents)'로의 진화:

지금까지의 '컴퓨터 유즈(Computer Use)' 기술은 사용자의 로컬 화면을 직접 조작함으로써 인간 사용자가 PC를 사용할 수 없게 만들거나, 반대로 헤드리스 백그라운드에서 동작할 경우 에이전트가 어떤 페이지를 누르고 있는지 전혀 알 수 없는 불투명성 문제가 있었습니다. Hermes Bot Screen은 헤드리스 리눅스 호스트 위에 도커(Docker) 컨테이너 기반의 가상 X11/데스크톱 샌드박스를 구축하여, 에이전트에게 온전한 가상 컴퓨터를 제공합니다. 사용자는 터미널로 명령을 내리고 별도의 창에서 에이전트의 작업을 실시간으로 참관할 수 있어 작업 연속성, 실행 가시성, 보안 격리라는 3대 과제를 동시에 해결했습니다.

7. Workflow & How-To (재현 가능한 단계별 실행 워크플로우)

  1. 도커 컨테이너 환경 준비: 리눅스 호스트 또는 로컬 머신에서 도커 엔진을 가동하고, Hermes Bot Screen 전용 이미지를 빌드합니다 (Opus 5.5에 프롬프트하여 자동 생성 권장).
  2. 화면 서브시스템 가동: 터미널에서 hermes computer use screen start를 실행하여 가상 데스크톱 버퍼를 백그라운드에 생성합니다.
  3. 작업 지시 및 브라우징 모니터링: 터미널에서 목표 URL 방문(예: julianoldie.com)을 지시한 후, 봇스크린 뷰어를 통해 브라우저가 열리고 링크를 클릭하는 과정을 실시간 확인합니다.
  4. 스케줄 태스크 바인딩: 매일 정해진 시각에 시장 조사, 데이터 스크래핑, 폼 제출을 수행하도록 스케줄 옵션을 부여하고 도커 컨테이너를 상시 가동합니다.
  5. 상태 확인 및 중지: 작업 완료 후 hermes computer use screen status로 실행 상태를 확인하거나 screen stop으로 컨테이너를 정상 종료합니다.
