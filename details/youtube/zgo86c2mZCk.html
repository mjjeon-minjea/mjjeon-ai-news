Claude Code Remote Control은 인바운드 포트를 열지 않고 TLS 암호화 아웃바운드 폴링 방식으로 Anthropic API와 통신하며, 파일 실행은 100% 로컬 머신에서 이루어지고 모바일 기기는 입력과 출력 화면만 동기화하는 보안 중심 원격 제어 아키텍처입니다.
