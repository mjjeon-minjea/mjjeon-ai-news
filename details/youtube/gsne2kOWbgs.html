5. Key Concepts & Architecture (핵심 개념 및 시스템 아키텍처)

5-Site 플라이휠 (Flywheel Architecture)

  • 단일 입력 → 5개 분기 생성: 1개 시드 키워드와 1개 실제 경험/사례를 Claude에 입력하여 상이한 앵글의 5개 기사 병렬 생성
  • 교차 링크 (Cross-Linking): 5개 도메인 간 맥락상 자연스러운 내부/외부 링크를 형성하여 도메인 권위(Domain Authority) 동반 상승
  • 데이터 재생산 루프: 발행된 5개 기사가 발생시키는 28일 GSC 노출 데이터를 다시 키워드 발굴 엔진의 입력값으로 순환

Gaps vs Leaks 진단 프레임워크

  • 콘텐츠 갭 (Gap): 구글이 이미 노출(Impressions)을 주고 있으나 전용 타깃 랜딩 페이지가 없어 순위가 20위권에 머무는 키워드 → 신규 페이지 즉시 생성
  • 트래픽 누수 (Leak): 1페이지 상위(예: 8위, 14,000회 노출)에 위치하나 제목/스니펫 매력도 부족으로 클릭률(CTR)이 1% 미만인 상태 → 제목 리라이팅 및 스키마 보강

  1. Phase 1: 인프라 및 사이트 셋업 (Day 1 - 14)

    11ty 정적 사이트 5개를 Netlify에 구축하고 각각 Google Search Console에 등록합니다. Google Cloud API를 발급하여 Agent OS와 GSC 계정을 연결합니다.

  3. Phase 3: 정체기 인내 및 데이터 기반 누수 수정 (Day 46 - 75)

    초기 1~3개월간 구글 신뢰도 샌드박스로 인해 트래픽이 평탄(Flat)하더라도 중단하지 않고 시스템을 가동합니다. 45일 차부터는 GSC 데이터를 분석해 14,000 노출 대비 CTR이 낮은 누수(Leak) 페이지 제목을 수정하고 스키마를 보강합니다.

  4. Phase 4: 지수 급등 및 AI Overviews 장악 (Day 76 - 90)

    구글 샌드박스가 풀리며 주간 80클릭에서 400클릭으로 급등하는 지수 성장을 수확합니다. 5개 사이트의 일관된 엔티티 언급으로 구글 AI 오버뷰와 Perplexity 답변 내 브랜드 인용을 장악합니다.
