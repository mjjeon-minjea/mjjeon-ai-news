2. 기술 아키텍처 및 메커니즘 분석

Hermes Agent Export/Import 아키텍처는 에이전트의 전체 런타임 상태(Identity, Skill Recipes, Vector/File Memory, Cron Schedules, Plugin Configurations, Desktop Themes)를 표준 아카이브 파일로 직렬화(Serialization)합니다. 내보내기 과정에서 민감한 `.env` 및 API 토큰을 자동으로 배제하여, 수신자가 자신의 API 인증 정보만 입력하면 즉시 동일한 지식과 행동 양식을 가진 복제 에이전트를 가동할 수 있습니다.

3. 핵심 기능 및 워크플로우 실증

  • 단일 명령 패키징 (export): `hermes export` 명령으로 머신 내 축적된 페르소나, 메모리, 스킬 일체를 보안 아카이브 파일로 압축
  • 안전한 크리덴셜 스트리핑: 내보내기 시 API 키 및 개인 계정 토큰을 자동 필터링하여 팀원 및 외부에 안전하게 전달
  • 무손실 복원 (import): 신규 머신에서 `hermes import ` 실행 후 본인 키만 입력하면 기존 스케줄과 기억을 완벽 계승
  • Agent OS 프로필 배포: Agent OS 대시보드에 사전 구성된 Hermes 프로필을 주입하여 세팅 시간 제로화
  • 스케줄 태스크 지속성: 이전 머신에서 설정된 오버나이트 리서치 및 일일 콘텐츠 크론잡이 복원 즉시 자동 재개
