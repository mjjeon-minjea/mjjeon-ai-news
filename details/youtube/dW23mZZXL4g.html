Grok Bot은 xAI가 2026년 8월 11일 출시한 상시 구동형 멀티 에이전트 플랫폼입니다. 복잡한 터미널이나 서버 설정 없이 WhatsApp/iMessage 형태의 친숙한 메신저 UI로 동작하며, 백그라운드에서는 계정 전용 클라우드 컴퓨터 인스턴스가 24/7 가동됩니다. 각 봇은 고유한 가상 화면을 점유하여 5개 이상의 봇이 브라우징, 파일 작업, 터미널 명령을 병렬 실행할 수 있습니다. 특히 봇 간 자율 인박스 통신, 스케줄/트리거(Slack, GitHub 등) 루틴, 그리고 사용자의 화면 조작을 녹화해 자율 실행 코드로 변환하는 'Teach a Task' 기능을 네이티브 지원합니다.

  • 그룹 채팅 내 다중 봇 협업: 단일 단체 대화방에서 리서치 봇, 콘텐츠 봇, CEO 봇이 상호 토론하며 전략 및 아티클 도출
