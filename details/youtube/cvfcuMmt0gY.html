2. 기술 아키텍처 및 메커니즘 분석

Hermes Agent OS의 Loop 시스템은 '상태 유지(Stateful) 대화 컨텍스트 + 주기적 백그라운드 폴링 + 비동기 메신저 알림' 구조로 설계되었습니다. 무상태(Stateless) 타이머 방식인 Cron과 달리, 작업 도중 사용자가 지시를 수정하더라도 에이전트가 이전 맥락을 완전히 파악한 상태에서 목표 도달 여부를 능동 판단합니다.
