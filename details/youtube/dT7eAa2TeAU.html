7. Workflow & How-To (터미널 무료 연동 및 프로필 생성)

  1. Step 1: Hermes 환경 설정 메뉴 실행 hermes setup

    대화형 프롬프트에서 모델 프로바이더 목록 중 open-code를 선택합니다.

  2. Step 2: 무료 MiMo Flash 모델 바인딩

    제공되는 모델 목록에서 mimo-v2.6-flash-free를 선택하여 추가 API 결제 등록 없이 인증을 완료합니다.

  3. Step 3: 독립 전용 프로필 생성 hermes profile create mimo-flash

    기존 Claude 및 Grok 프로필에 영향을 주지 않는 전용 샌드박스를 구성합니다. 1조 Pro 모델 사용 시에는 hermes profile create mimo-pro를 입력합니다.

  4. Step 4: 자율 툴 실행 및 스킬 학습 검증 /learn [GUIDE_URL]

    에이전트에게 기술 문서 가이드를 제공하여 자율 파싱 및 신규 에이전트 스킬 생성 여부를 확인합니다.
