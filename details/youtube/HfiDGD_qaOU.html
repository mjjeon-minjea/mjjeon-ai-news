3. The Big Idea (핵심 문제와 해결책)

단순 대화형 음성 AI의 한계

기존의 음성 AI는 질문에 답변만 해주는 검색엔진 대화창에 불과하여, 실제 문서를 만들거나 외부 앱을 조작하려면 결국 키보드와 마우스로 돌아와 수작업을 해야 했습니다.

음성 제어 콘솔(Control Panel) 패러다임

이번 업데이트로 ChatGPT Voice는 대화 도구가 아닌 '실행 제어판'으로 탈바꿈했습니다. 운전 중이나 이동 중 음성으로 지시하면 ChatGPT Work와 플러그인이 백그라운드에서 문서를 빌드하고, 통화 종료 후에도 작업이 유지되어 자투리 시간을 완벽한 생산 시간으로 전환합니다.

5. Key Concepts & Architecture (핵심 아키텍처)

음성 런타임 아키텍처

  • GPT Live 1 엔진: 음성 입출력을 단일 엔드투엔드로 동시 처리하며, 복잡 추론 시 상위 모델(Reasoning)로 라우팅.
  • Tool Invocation Pipeline: 음성 스트림 중 도구 호출 파라미터를 감지하여 연결된 플러그인 API 즉시 트리거.
  • Persistent Task Session: 음성 채널이 닫혀도 워크스페이스 세션은 유지되어 텍스트 렌더링 지속.

보안 및 인터랙션 거버넌스

  • Human-in-the-Loop On-Screen Guard: 금융/메일 전송 등 위험 액션 시 스피커 음성 승인 불인정, 디바이스 물리 터치 강제.
  • 30-Day Ephemeral Retention: 음성 클립은 30일간 보관되며 채팅 삭제 시 자동 파기.
  • Rolling Quota Window: 플랜별 24시간 롤링 사용량 제한 정책 적용.
