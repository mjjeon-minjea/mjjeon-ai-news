1. 핵심 총괄 요약 (Executive Summary)

  • 주요 핵심: MIT 라이선스로 전면 무료 공개된 Ornith-1.5를 활용한 4대 실전 비즈니스 자동화 워크플로우 실증
  • 주요 핵심: 통화 대본 기반 주간 콘텐츠 캘린더 생성, 반응형 랜딩페이지 카피라이팅, 5단계 이메일 온보딩 시퀀스, 타겟 광고 캠페인 자동 기획
  • 주요 핵심: VLLM, Ollama(GGUF), Apple Silicon MLX를 활용하여 OpenAI 호환 로컬 API 엔드포인트로 즉시 전환하는 배포 가이드

2. 기술 아키텍처 및 메커니즘 분석

Ornith-1.5는 OpenAI API 표준과 100% 호환되는 엔드포인트를 제공하므로, 기존 자동화 도구(n8n, Cursor, Agent OS 등)에서 Base URL 한 줄 변경만으로 완벽한 프라이빗 로컬 인프라 전환이 가능합니다.

3. 핵심 기능 및 워크플로우 실증

  • 주간 콘텐츠 팩: 1회 코칭 통화 녹취록에서 숏폼 훅 5개, 이메일 제목 3개, 본문 글 10개, 14일 캘린더를 60초 내 생성
  • 랜딩페이지 카피: 핵심 혜택, 반론 극복(Objection Handling), 전환 CTA를 포함한 전체 구조 원스톱 작성
  • 온보딩 이메일: 신규 회원의 리텐션을 극대화하는 5단계 자동 발송 이메일 시퀀스 빌드
  • 광고 캠페인: 주요 페인포인트 3종을 겨냥한 9개 광고 컨셉과 A/B 헤드라인 테스트 안 기획

  1. 단계 1: vLLM 또는 Ollama를 설치하고 `ornith-1.5-35b` 가중치를 다운로드합니다.
