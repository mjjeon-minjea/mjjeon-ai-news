5. Key Concepts & Architecture (핵심 아키텍처)

개방형 상호운용 표준 (Open Standards)

  • Model Context Protocol (MCP): LLM과 로컬/원격 데이터 저장소 간의 표준화된 보안 컨텍스트 인터페이스.
  • Agent Skills 규격: 단일 작업 절차와 실행 스크립트를 패키징하여 에이전트에게 주입하는 실행 모듈.
  • Unified Discovery Directory: 분산된 서드파티 툴을 검증 후 단일 마켓플레이스 카탈로그로 통합.

3계층 에코시스템 구조

  • Layer 1 (Data & Tool Connectors): 엔터프라이즈 원본 저장소와 실시간 동기화.
  • Layer 2 (Turnkey AI Products): 도메인 특화(코딩, 법률, 보안, 데이터웨어하우스) 버티컬 완제품.
  • Layer 3 (Enterprise Transformation Services): 대규모 전사 도입을 지원하는 글로벌 SI 컨설팅 네트워크.
