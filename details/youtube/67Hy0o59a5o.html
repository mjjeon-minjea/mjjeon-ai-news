8.2 Anthropic 공식 권장 CLAUDE.md 거버넌스 규칙

# CLAUDE.md Rules 1. Autonomy: If a step does not need my input, keep going. Put status notes in the same message as your next action. 2. Safety Gate: Only stop and ask me when you cannot continue without clarification, or before anything destructive (e.g. deleting files, force pushing Git, modifying files outside this workspace). 3. Context Survival: Maintain a running checklist in tasks.md. Tick items off as completed. 4. Run Summary: End every multi-step run with three distinct headings: - Blocked: (items waiting on user) - Changed: (concrete modifications made) - Found: (key insights or unexpected discoveries)

8.3 서브에이전트 분할 및 증거 취합 프롬프트

Audit every file in /src for performance bottlenecks and broken dependencies. Delegate each subdirectory to its own dedicated sub-agent.
