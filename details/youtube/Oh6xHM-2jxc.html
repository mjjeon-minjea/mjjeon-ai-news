  1. 입력 데이터 소스 정리: 영업 통화 녹음본이 저장되는 구글 드라이브 폴더 경로와 사내 영업 표준 매뉴얼(Sales Process Playbook) 문서를 준비합니다.
  2. GPT-6 Astra 프롬프트 바인딩: Agent OS 내에서 GPT-6 Astra를 호출하고, 구글 드라이브 연동 권한을 부여한 뒤 전수 분석 대시보드 탭 생성을 요청합니다.

  4. 24시간 야간 스케줄 등록: Hermes Agent 또는 로컬 크론(Cron)을 통해 매일 새벽에 신규 통화를 일괄 평가하도록 백그라운드 스케줄을 활성화합니다.
  5. Obsidian 메모리 연동: 분석된 고객 반응, 빈출 반론, 긍정 피드백을 Obsidian 마크다운 볼트에 자동 저장하여 타 에이전트(Content, SEO)가 참조할 수 있도록 구성합니다.
  6. 3단계 검증 주기 적용: 1단계 기능 명세 → 2단계 빌드 및 조정 → 3단계 7일간 실사용 트래킹을 거쳐 실제 업무 효율이 입증된 기능만 정식 채택합니다.
