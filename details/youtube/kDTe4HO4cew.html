01 이 영상이 답하는 핵심 질문

  • Q1. 구글이 공개한 새로운 온디바이스 번역 솔루션은 무엇인가?
    → 구글이 소형 경량 언어 모델인 Gemma 4 E2B(2B 파라미터)를 활용하여 오프라인 전용 하드웨어 통번역기 프로젝트인 Gemma Translator를 공개함.
  • Q2. 어떤 하드웨어 환경에서 어떻게 구동되는가?
    → 라즈베리 파이 5(Raspberry Pi 5) 단일 보드 컴퓨터 상에서 로컬로 모델을 직접 추론하며, 마이크, 스피커, LCD 디스플레이 및 물리 다이얼/버튼이 결합된 하드웨어 케이스 형태로 구동됨.
  • Q3. 기존 클라우드 기반 구글 번역기와 무엇이 다른가?
    → 인터넷/클라우드 연결이 전혀 필요 없는 100% 독립 오프라인(On-Device Offline) 환경에서 실시간 음성 인식, 양방향 번역, 텍스트 및 음성 출력을 수행함.

03 The Big Idea

1. 기존 번역기의 문제점

스마트폰 구글 번역기 및 대형 AI 통번역기는 해외 여행, 산간/사막 오지, 항공기 기내 등 네트워크가 불안정하거나 인터넷이 차단된 환경에서 사용이 제한되며, 클라우드 API 호출에 따른 지연(Latency)과 데이터 프라이버시 이슈가 존재함.

2. Gemma Translator의 혁신

2B급 초경량 SLM(Small Language Model)을 $80대의 저전력 SBC(Raspberry Pi 5)에 포팅하여, 통신 비용과 서버 의존성 0%의 완전 자립형 전용 AI 번역 하드웨어 생태계를 제시함.

05 핵심 기술 개념 & 구조

1. 온디바이스 경량 LLM 추론 (Edge SLM Inference)

서버 통신 없이 로컬 CPU/NPU(또는 Pi 5 내장 ARM 프로세서)에서 2B 파라미터 모델을 4비트/8비트 양자화(Quantization)하여 직접 실행하는 경량화 아키텍처.

2. 완전 격리형 오프라인 번역 파이프라인 (Local Speech-to-Speech)

오디오 입력(마이크) → 로컬 ASR(음성인식) → Gemma 4 번역 추론 → 로컬 TTS(음성합성) 및 LCD 텍스트 출력을 네트워크 패킷 송수신 없이 폐쇄 루프로 처리.

07 하드웨어 구성 및 작동 흐름

Gemma Translator 작동 메커니즘

  1. 언어 페어 설정: 기기 전면의 다이얼/스위치로 출발어(Source, 예: Spanish)와 도착어(Target, 예: Chinese) 지정.
  2. 음성 입력: 상단 마이크 버튼을 누르고 음성 발화.
  3. 로컬 번역 처리: 라즈베리 파이 5에 적재된 Gemma 4 E2B 모델이 실시간 로컬 번역 수행.
  4. 화면 표시 및 음성 출력: LCD 화면에 원문/번역문 텍스트를 병렬 출력하고 스피커로 타깃 언어 음성 재생.
