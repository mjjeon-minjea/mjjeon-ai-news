2. 기술 아키텍처 및 메커니즘 분석

DeepSeek-V4-Fl-vision-FX는 기존 V4 Flash의 경량 텍스트 추론 성능을 그대로 유지하면서 시각 임베딩 인코더를 결합한 멀티모달 모델입니다. 파일 확장자가 아닌 바이너리 매직 바이트를 통해 JPEG, PNG, GIF, WEBP 형식을 엄격히 검증하며, 모든 입력 이미지를 800x800 규격으로 리사이징하여 이미지당 정확히 384토큰으로 고정 처리합니다.

3. 핵심 기능 및 워크플로우 실증

  • Base64 인라인 주입: 로컬 PC의 단일 이미지를 Base64 문자열로 인코딩하여 요청 본문에 직접 전달
  • 공개 URL 다운로드: 최대 8,192자 이내의 공용 이미지 URL을 모델이 60초 이내에 직접 다운로드하여 분석
  • Files API 캐싱 (권장): 이미지를 1회 업로드하여 File ID를 획득한 후 반복적인 에이전트 턴에서 토큰 및 대역폭 낭비 없이 재참조
  • 디테일 모드 제어: low (512x512 다운샘플링 고속 처리) vs original (원본 해상도 유지 정밀 분석) 선택
