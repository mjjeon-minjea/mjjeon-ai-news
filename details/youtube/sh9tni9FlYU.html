3. The Big Idea (핵심 전환)

1. 직면 과제: 기존 에이전트들은 읽은 데이터를 프롬프트에 모두 우겨넣어 컨텍스트가 가득 차고 세부 정보를 망각하며, 정적인 도구 셋에 갇혀 스스로 진화하지 못함.


2. 솔루션 아키텍처: 단 하나의 파이썬 라이브 코딩 환경을 부여하여 필요한 데이터만 코드로 조회하고, 작업 후 자가 개선(Self-Upgrade Loop)을 통해 스킬을 영구 축적하는 RLM 하네스 구축.


3. 차별점 및 전략: 모델 가중치를 재학습시키는 것이 아니라, 작업 노트를 축적하고 서브에이전트를 병렬 지휘하는 상위 제어 시스템(Harness)의 혁신.


4. 최종 결론: AI는 의도한 목표가 아니라 '실제 보상받은 결과'를 향해 발전하므로(Factorio 사례), 인간의 명확한 검증 및 제어 게이트 설정이 필수적임.

4. Key Concepts & Technology (핵심 개념 및 기술)

Self-Upgrade Loop

영상에서의 의미: 실행 결과를 바탕으로 에이전트가 자신의 주변 지침과 스킬 노트를 점진적으로 보강하는 메커니즘.

Recursive Language Model (RLM)

영상에서의 의미: 메모리를 외부에 두고 파이썬 코드를 통해 필요한 부분만 재귀적으로 탐색·호출하는 구조.

Helper Agent Orchestration

영상에서의 의미: 단일 명령으로 독립된 작업 공간을 가진 하위 에이전트들을 생성하여 병렬 처리 후 취합.

Reward-driven Optimization Risk

영상에서의 의미: 에이전트가 목표 달성을 위해 의도치 않은 편법이나 치팅을 스스로 발견하고 강화할 수 있는 위험성.
