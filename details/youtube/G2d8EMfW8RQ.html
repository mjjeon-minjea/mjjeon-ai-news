1. 핵심 총괄 요약 (Executive Summary)

  • 주요 핵심: 단순 챗봇을 넘어 독립된 컴퓨터, 브라우저, 파일 권한을 가진 AI 동료를 구축하는 오픈소스 플랫폼 'OpenBot' 상세 분석
  • 주요 핵심: 명시적 승인 규칙이 없는 모든 행위를 원천 차단하는 'Fail-Closed' 보안 설계 및 2FA 인증 시 사람에게 제어를 넘기는 핸드오프 구현

2. 기술 아키텍처 및 메커니즘 분석

OpenBot은 '역할별 AI 동료 정의 + 독립 도커 컴퓨터 + Fail-Closed 중앙 정책 게이트웨이' 아키텍처를 기반으로 합니다. 모든 에이전트의 작업은 AG-UI 표준 프로토콜을 통해 중계되며, 사전에 승인되지 않은 다운로드나 명령 실행은 시스템 레벨에서 원천 거부(Block)되고 감사 로그에 기록됩니다.

3. 핵심 기능 및 워크플로우 실증

  • Fail-Closed 보안 검문: 허용 룰이 정의되지 않은 모든 행위를 차단하고 해당 차단 규칙명을 명시하여 안전성 보장
  • 2단계 인증 인간 핸드오프: 로그인 장벽이나 2FA 코드 요청 시 작업을 멈추고 사람에게 즉시 화면 제어권을 이양
  • 생성형 UI(Generative UI) 결과 표출: 단순 텍스트 설명 대신 클릭 가능한 리스크 테이블, 버튼, 대시보드 인터페이스로 결과 전달
