  • 베라 루빈 NVL72 랙 시스템과 88코어 올림푸스 기반 베라 CPU(LPDDR5X 소캠 채택), 온칩 128GB SRAM 기반 Groq 3 LPX 추론 가속기 통합을 공개했습니다.
  • HBM4(초고속), GDDR7(장문맥 대용량), LPDDR5X(저전력), SRAM(초저지연)으로 재편된 다층 메모리 계층에서 삼성전자의 종합 메모리 포트폴리오 기회가 부각되었습니다.

제작자 주장 · 엔비디아가 오픈 에이전트 비전을 표방하면서도 실제로는 자체 스택(다이나모, 네모클로) 내에 에이전트 통제 계층을 수직 결속하고 있다는 분석적 해석 제시.

광고·홍보 · 없음 (공식 행사 분석 및 안될공학 인스타그램 채널 소개 포함)

외부 검증 필요 · 삼성전자의 LPDDR5X 소캠(SOCAMM) 엔비디아 루빈 플랫폼 독점 공급 여부는 미확정 상태로 고객사 승인 단계 추적 필요.

실제 시연 · 베라 루빈 NVL72 무케이블 직결 백플레인, 베라 CPU 88코어 및 LPDDR5X 모듈, 다이나모 1.0 추론 OS 구동 시연.

실무 시사점 · AI 인프라 경쟁력이 단순 GPU 단품 연산력에서 전력 효율, 네트워크 대역폭(NVLink 6/CPO), 이종 메모리 오케스트레이션 단위로 전환됨.
