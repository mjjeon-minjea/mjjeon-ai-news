Hermes 공식 문서, 업데이트 사전 계획과 다중 프로필 보호 강화

공식 문서와 저장소 교차확인 완료 · 다중 프로필 업데이트 안전성 강화 · 자동 업데이트 불필요

Hermes Agent docs expand update planning and multi-profile safeguards · published 2026-08-21T20:01:35Z · reviewed 2026-08-21T23:23:15Z

핵심 요약
Hermes Agent 공식 업데이트 문서에 변경 없이 설치 유형·실행 중인 프로필별 서비스·감독 방식·실행 코드 버전·재시작 방식을 보여주는 `hermes update --plan`이 추가됐습니다. 실제 업데이트 전 빠른 상태 스냅샷도 호출한 프로필 하나가 아니라 설치된 모든 프로필에 각각 생성되며, 업데이트 영수증과 종료 후 프로필별 실행 버전 점검으로 혼합 버전 상태를 실패로 드러냅니다.
왜 중요
여러 Hermes 프로필과 Gateway를 한 서버에서 운영할 때 업데이트 대상과 예상 재시작 범위를 먼저 확인하고, 각 프로필의 설정·예약 작업을 별도 스냅샷으로 보호할 수 있습니다. 업데이트 뒤 일부 Gateway만 이전 코드를 계속 실행하는 상태도 자동화 성공으로 오인하지 않게 됩니다.
우리 영향
다중 프로필 운영자의 업데이트 점검·복구 안전성이 높아지는 공식 운영 변경입니다. 특정 설치·릴리스 버전 발표는 아니며 현재 설치본이 이 기능을 포함한다는 뜻도 아니므로, 공식 Releases와 실제 설치 버전을 별도로 확인해야 합니다.
지금 할 일
업데이트가 필요하면 먼저 읽기 전용 `hermes update --plan`으로 설치 유형과 전체 프로필·서비스·재시작 계획을 확인합니다. 실제 업데이트는 공식 Releases와 현재 설치 방식을 확인하고 중단 영향과 복구 수단을 승인한 뒤 수행하며, 이 문서 신호만으로 자동 업데이트하지 않습니다.
